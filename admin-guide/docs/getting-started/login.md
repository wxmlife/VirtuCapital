## 1. 系统登录与基础设置

### 1.1 登录系统

**操作路径**：打开组织提供的管理员端网址 → 输入管理员账号和密码 → 点击「登录」

1. 确认网址、协议和域名均与组织提供的信息一致，不要从陌生邮件或聊天链接进入；
2. 输入分配给本人的管理员账号和密码；
3. 点击「登录」，等待后台首页完整加载；
4. 首次使用或权限刚变更时，检查左侧导航是否与获批角色一致。

### 1.2 登录失败与会话异常

- **账号或密码错误**：检查大小写、输入法和账号是否属于管理员角色；不要连续尝试大量密码。
- **登录后返回登录页**：确认会话是否过期，再重新登录；若反复发生，记录发生时间和当前网址后联系内部技术支持。
- **页面长期停在加载状态**：先刷新一次；仍未恢复时保留错误文字和路由，不要重复提交业务操作。
- **权限菜单缺失**：先确认当前账号角色；角色刚调整时应退出后重新登录。

### 1.3 登录后基础控制

| 功能 | 使用方法 |
| --- | --- |
| **语言** | 使用侧边栏底部的语言入口切换 English、繁体中文或简体中文；切换后确认当前页面标题和字段已更新 |
| **主题** | 使用侧边栏顶部的主题按钮切换深色或浅色模式；该操作只改变显示方式 |
| **当前账号** | 侧边栏底部显示当前登录名称，用于确认没有误用他人会话 |
| **退出登录** | 完成工作后点击侧边栏底部的「退出登录」，确认页面回到登录状态 |

### 1.4 安全退出检查

1. 确认正在编辑的表单已按业务需要保存为草稿或已明确放弃；
2. 关闭仍展开的客户资料、附件和敏感详情；
3. 点击「退出登录」，不要只关闭浏览器标签页；
4. 在共享设备上同时关闭浏览器窗口，避免会话被恢复。
