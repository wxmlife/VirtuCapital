##
仪表盘是管理员登录后的默认首页，提供平台核心数据的 **实时监控**。

### 市场概览卡片

| 指标 | 说明 |
| --- | --- |
| 总投资者数 | 平台注册投资者的总人数 |
| 总资产（HKD） | 所有投资者资产的总和（按当前汇率折算为港币） |
| 股票价值（HKD） | 所有投资者持有股票的市值总和 |
| ├── W/L 24小时盈亏 | 最近24小时内股票市值的盈亏变化 |
| 现金 | 平台所有投资者各币种的现金余额汇总 |
| ├── HKD | 港币现金余额 |
| ├── USD | 美元现金余额 |
| └── USDT | USDT 余额 |

:::tip 用途
快速掌握平台整体资产规模和资金分布情况。
:::

![仪表盘](../assets/V102/FirstPage.png)

### 黄河账户

显示平台账户的可见币种余额。
- 美元余额
- 港元余额\
余额用于查看和核对；实际调拨、入账或出账应从对应业务流程执行。

### 快捷操作

快捷卡片可进入投资者、股票管理、市场数据和消息模板等常用页面。点击后应确认页面标题与目标一致，再执行操作；浏览器返回不会自动撤销已经保存或提交的内容。

### 系统信息

| 项目 | 说明 |
| --- | --- |
| **应用程序** | 当前后台应用名称 |
| **版本** | 当前部署版本，用于故障定位 |
| **环境** | 当前运行环境；测试与正式环境的数据不可混用 |

![系统信息](../assets/V102/dashboard-information.png)

### 日常巡检建议

1. 确认总资产、股票价值和现金没有无法解释的突变；
2. 检查平台账户余额与最近完成的资金记录是否一致；
3. 查看「记录」菜单是否出现待办红点；
4. 检查市场数据的最近同步状态；
5. 报告问题时附上页面、时间、环境和版本，但不要附带未脱敏的客户资料。
