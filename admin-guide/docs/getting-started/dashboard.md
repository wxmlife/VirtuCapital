## 2. 仪表盘概览

仪表盘是管理员登录后的概览页，用于快速判断平台资产、账户余额和系统状态。数值的统计口径、币种和更新时间以页面当前标注为准。

### 2.1 市场概览卡片

| 指标 | 说明 |
| --- | --- |
| **总投资者数** | 当前纳入统计的投资者数量 |
| **总资产（HKD）** | 按页面汇率口径折算后的资产汇总 |
| **股票价值（HKD）** | 投资者股票市值汇总 |
| **现金** | HKD、USD、USDT 等币种余额汇总 |

卡片用于发现明显异常，不应代替业务明细或会计对账。数值异常时，依次核对市场数据汇率、股票行情、投资者持仓和资金记录。

### 2.2 黄河账户

该区域显示平台账户的可见币种余额，例如美元和港元。余额仅用于查看和核对；实际调拨、入账或出账应从对应业务流程执行。

> ⚠️ 仪表盘余额与业务记录不一致时，不要通过重复审核或重复录入来“修正”显示。先定位原始记录和审计日志。

### 2.3 快捷操作

快捷卡片可进入投资者、股票管理、市场数据和消息模板等常用页面。点击后应确认页面标题与目标一致，再执行操作；浏览器返回不会自动撤销已经保存或提交的内容。

### 2.4 系统信息

| 项目 | 说明 |
| --- | --- |
| **应用程序** | 当前后台应用名称 |
| **版本** | 当前部署版本，用于故障定位 |
| **环境** | 当前运行环境；测试与正式环境的数据不可混用 |

### 2.5 日常巡检建议

1. 确认总资产、股票价值和现金没有无法解释的突变；
2. 检查平台账户余额与最近完成的资金记录是否一致；
3. 查看「记录」菜单是否出现待办红点；
4. 检查市场数据的最近同步状态；
5. 报告问题时附上页面、时间、环境和版本，但不要附带未脱敏的客户资料。
