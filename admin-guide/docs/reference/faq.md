##
### Q1：为什么我的审核操作没有立即生效？

**A**：汇率、系统设定及部分高风险业务需要提交审核。普通管理员完成初审或提交后，记录可能进入「待超级管理员审核」；在终审通过前，当前生效值不会改变。请在「记录」中按状态查找，并核对详情和操作日志。

### Q2：如何处理「超分配股票」？

**A**：「超分配」表示已分配数量超过后台设定的总仓数。停止继续分配，核对股票代码、总仓数、各投资者数量及最近审计记录。确认原因和批准的修正方案后再处理，不能通过新增重复股票来抵消异常。

### Q3：投资者忘记密码怎么办？

**A**：管理员不能查看用户密码，也不应代用户设置或收集密码。请引导用户使用客户端当前提供的账号恢复流程；无法恢复时，通过组织授权的身份核验与支持流程处理。

### Q4：系统出现异常数据怎么办？

**A**：
1. 停止重复提交、审核或保存；
2. 记录发生时间、环境、页面路由和业务记录 ID；
3. 查看审计日志，确认最近是否有相关变更；
4. 涉及价格或资产时检查市场数据同步和汇率模式；
5. 通过内部支持流程提交已脱敏信息。

### Q5：如何修改自己的管理员信息？

**A**：当前后台可直接使用语言和主题控制，并可安全退出。若页面没有个人资料或密码修改入口，不要依据旧手册猜测；请按组织的账号管理流程申请变更。

### Q6：为什么有些记录显示「待超级管理员审核」？

**A**：该状态表示管理员阶段已经完成，但流程仍要求具备终审权限的人员复核。常见于系统设定、人工汇率及页面标记为需要终审的资金或持仓业务。具体以记录详情显示的待办和生命周期为准。

### Q7：如何查看某个投资者的所有操作记录？

**A**：
1. 在「投资者」中按姓名、手机号、邮箱或 VC User ID 精确定位；
2. 打开详情，查看页面提供的账户、资产和业务记录区块；
3. 需要完整后台操作留痕时，前往「审计日志」，使用目标用户 ID 和时间范围检索。

### Q8：企业开户草稿在哪里继续？

**A**：进入「客户管理 → 企业用户」，找到资料状态为草稿的企业记录，在操作菜单选择「继续开户」。先检查当前阶段和已上传文件，再继续填写；不要为同一企业重复建立草稿。

### Q9：消息模板预览仍显示变量怎么办？

**A**：检查 Payload JSON 的字段名称是否与「可用变量」完全一致，必填变量是否都有测试值，以及 JSON 是否有效。预览通过前不要保存生产文案；预览不会发送真实消息。

### Q10：市场数据同步失败怎么办？

**A**：先点击「刷新」确认最新状态，再查看对应市场的上次同步时间、触发来源和错误状态。不要同时重复触发多个同步任务；中国 A 股等显示「不可同步」的市场无需强制操作。

### Q11：页面跳转后出现 `ChunkLoadError` 或红色错误遮罩怎么办？

**A**：先停止当前操作并刷新页面；确认没有重复提交后重新登录。若仍出现，记录出错前后的路由、时间、环境和完整错误文字，通过内部技术支持流程上报。错误消失前不要继续审核、保存或提交表单。
