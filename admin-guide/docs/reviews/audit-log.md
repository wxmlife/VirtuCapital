## 7. 审计日志

**操作路径**：左侧导航栏 → 「审计日志」

审计日志记录管理员对用户、交易、股票和系统配置等资源执行的操作，用于安全审计和问题追溯。

![审计日志列表与筛选条件](../assets/V102/audit-log-list.jpg)

### 7.1 查询日志

可组合使用以下条件：

| 条件 | 说明 |
|------|------|
| **关键字** | 搜索操作名称或摘要 |
| **操作类型** | 创建、修改、删除、审核等 |
| **结果** | 成功或失败 |
| **资源类型 / 资源 ID** | 定位被操作的业务资源 |
| **管理员用户 ID** | 定位操作执行人 |
| **目标用户 ID** | 定位受影响用户 |
| **开始时间 / 结束时间** | 限定操作发生的时间范围 |

设置条件后执行搜索；需要查看刚发生的操作时，点击「刷新」重新获取数据。

### 7.2 日志字段与详情

列表展示时间、操作、管理员、目标用户、资源类型与 ID、结果、来源 IP、摘要及详情入口。点击「查看详情」可核对请求参数、变更内容和执行结果等完整信息。

排查问题时建议按以下顺序缩小范围：

1. 先用时间范围和结果定位异常批次；
2. 再用管理员 ID、目标用户 ID 或资源 ID 找到具体记录；
3. 检查来源 IP、操作摘要和详情，确认谁在何时对什么资源执行了什么操作；
4. 使用分页继续查看同一时间段的其他记录。
