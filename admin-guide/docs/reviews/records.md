## 6. 记录审核

**操作路径**：左侧导航栏 → 「记录」

记录页统一展示订单、入金、出金、换汇、股票转让和转仓等业务。菜单出现红点时，表示存在待处理记录。

![待审核记录列表](../assets/V102/records-pending-list.jpg)

### 6.1 检索记录

| 条件 | 说明 |
|------|------|
| **记录类型** | 全部、订单、入金、出金、换汇、股票转让、转仓、后台操作等 |
| **投资者** | 按姓名、邮箱、手机号或投资者 ID 搜索 |
| **审核状态** | 无需审核、待审核、待超级管理员审核、已通过、已拒绝、已取消 |
| **股票** | 按代码、Ticker、Stock Key 或名称搜索 |

点击「套用筛选」执行查询，「重设」清空条件，「刷新」获取最新状态。列表展示投资者、股票、操作类型、待办事项、数量、金额、时间、审核状态、业务状态和详情入口，并支持分页。

### 6.2 通用审核原则

1. 打开详情，核对申请人、金额或数量、附件及关联账户；
2. 检查冻结资金或持仓是否足够，手续费是否正确；
3. 对照生命周期、关联交易和操作日志确认状态一致；
4. 审核通过前再次确认关键数据；拒绝时填写明确原因；
5. 出金和转仓等高风险操作在管理员通过后，仍需超级管理员二次审核。

### 6.3 股票转入审核

详情页显示转仓单号、操作类型、业务与审核状态、投资者、目标券商、原始券商、来源账户、结算参与者代码、转入股票及数量、附件、生命周期、操作日志和审核入口。

![股票转入详情](../assets/V102/records-inbound-transfer-detail.jpg)

核对原券商转出确认、来源账户、目标券商、股票代码、数量和申请文件是否一致。附件或资料不完整时不要通过；填写明确审核意见后执行通过或拒绝，并继续检查生命周期是否进入下一状态。

### 6.4 股票转出审核

详情页重点包括接收券商、接收账户、联系人、转出股票与数量、冻结持仓、手续费、市值、申请附件、生命周期、关联资金记录和操作日志。

![股票转出详情](../assets/V102/records-outbound-transfer-detail.jpg)

审核时确认接收资料完整、冻结数量足够、费用正确，且申请表、签名和券商结单与申请一致。管理员通过后按流程等待超级管理员复核；最终状态应与持仓释放、关联资金记录和生命周期同步。

### 6.5 股票转让审核

股票转让详情展示转出方与接收方、股票、数量、协定价格、协定金额、币种、BSN、冻结持仓、关联交易和操作日志。

![股票转让详情](../assets/V102/records-stock-transfer-detail.jpg)

重点核对双方身份、数量、价格及金额计算，确认转出方持仓已正确冻结，且不存在重复或冲突交易，再执行通过或拒绝。

### 6.6 其他记录

- **现金入金**：核对入金方式、币种、金额、手续费、付款账户与凭证；通过后核对关联入账流水及余额变化；
- **现金出金**：核对收款账户、可用余额、冻结金额、手续费和附件；管理员初审后按流程等待终审；
- **订单、买卖、换汇**：核对可用资金或持仓、价格、手续费和市场状态；
- **资料变更**：比较变更前后信息，敏感资料需额外验证；
- **后台操作**：核对操作人、目标资源、变更摘要和执行结果。

典型审核状态为：已提交 → 待审核 → 管理员已通过 → 待超级管理员审核 → 已完成；任一审核环节均可能因资料不符转为已拒绝，用户主动取消则显示已取消。

### 6.7 审核后的复核

1. 刷新记录并确认审核状态已经更新；
2. 核对业务状态、资金或持仓状态与审核结果一致；
3. 检查关联交易、生命周期和操作日志没有停留在中间状态；
4. 对高风险业务等待终审，不要重复点击审核按钮；
5. 状态不一致时停止后续操作，并使用记录 ID 到审计日志中排查。
