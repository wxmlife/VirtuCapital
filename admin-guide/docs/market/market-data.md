**操作路径**：左侧导航栏 → 「市场数据」

市场数据页用于管理业务生效汇率，并查看中国 A 股、港股和美股的数据同步状态。页面右上角提供「强制重新同步」「同步全部」和「刷新」操作；单个市场也可独立同步。

### 汇率模式

管理员可选择客户端资产换算和货币兑换使用哪套汇率：

| 模式 | 说明 |
|------|------|
| **市场汇率** | 使用 HKAB 自动同步的汇率快照 |
| **手动汇率** | 使用后台录入的业务汇率 |

切换模式后点击「**提交审核**」 ，超级管理员审核通过后才会生效。页面同时显示当前启用模式、数据来源、汇率日期和最近同步时间。

![市场汇率模式与市场同步状态](../assets/V102/market-data-market-rate.jpg)

### 汇率更新

系统支持以下六组汇率：

| 汇率对 | 汇率对 |
|--------|--------|
| 1 HKD → USD | 1 USD → HKD |
| 1 HKD → USDT | 1 USD → USDT |
| 1 USDT → HKD | 1 USDT → USD |

- 在市场汇率模式下，可点击「同步市场汇率」获取最新快照。
- 在手动汇率模式下，填写各汇率数值后提交审核；审核通过前不会影响当前业务汇率。

![手动汇率录入与提交审核](../assets/V102/market-data-manual-rate.jpg)

### 股市数据同步

各市场卡片展示：

| 字段 | 说明 |
|------|------|
| **交易所 / 股票 / ETF / 指数** | 当前已同步的数据量 |
| **同步状态** | 成功、失败或不可同步 |
| **上次同步 / 耗时** | 最近任务的时间与耗时 |
| **触发来源** | API、计划任务或后台手动触发 |
| **下次计划 / 计划标识** | 自动同步计划信息 |

- 「同步」仅同步对应市场；
- 「同步全部」依次同步所有受支持市场；
- 「强制重新同步」用于需要忽略已有状态、重新拉取全部数据的场景；
- 当前中国 A 股卡片显示「不可同步」时，按钮不可用，无需重复尝试。

> ⚠️ 强制同步可能耗时较长。执行前确认没有其他同步任务正在运行，完成后使用「刷新」查看最新状态。
