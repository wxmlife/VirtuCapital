## 5. 市场数据管理

### 5.1 汇率快照

**操作路径**：左侧导航栏 → 「市场数据」→「汇率快照」

市场数据页现在同时管理**市场汇率同步**、**手动汇率维护**和**汇率启用模式**。管理员可选择客户端资产换算与货币兑换实际使用市场汇率或手动汇率；提交后需由超级管理员审核。

![](../assets/33-marketData-exchangeRateMode.png)

#### 汇率列表

| 字段 | 说明 |
|------|------|
| **来源** | 汇率数据来源 |
| **汇率日期** | 当前汇率的生效日期 |
| **市场汇率｜固定汇率** | 切换汇率类型 |
| ├─ 自动刷新 | 系统自动从市场获取最新汇率 |
| └─ 人工编辑 | 管理员手动输入汇率（需提交审核） |

#### 汇率启用模式

| 模式 | 说明 |
|------|------|
| **市场汇率** | 使用 HKAB 自动同步得到的汇率快照作为业务生效汇率 |
| **手动汇率** | 使用后台手动输入的汇率作为业务生效汇率 |

**操作步骤**：
1. 在「汇率启用模式」区域选择市场汇率或手动汇率；
2. 点击「提交审核」；
3. 等待超级管理员审核通过后生效。

> 💡 **说明**：市场汇率抓取与手动汇率数值维护仍在市场数据页进行；「汇率启用模式」只控制当前业务实际使用哪一套汇率。

#### 支持的汇率对

| 汇率对 | 说明 |
|--------|------|
| 1 HKD → USD | 港币兑美元 |
| 1 USD → HKD | 美元兑港币 |
| 1 HKD → USDT | 港币兑USDT |
| 1 USD → USDT | 美元兑USDT |
| 1 USDT → HKD | USDT兑港币 |
| 1 USDT → USD | USDT兑美元 |

> ⚠️ **审核要求**：人工编辑的汇率需要提交审核，审核通过后生效。

![](../assets/09-marketData-exchangeRateDefault.jpg)
#### 编辑汇率操作步骤

1. 在对应汇率行点击「编辑」
2. 输入新的汇率数值
3. 点击「提交审核」
4. 等待超级管理员审核通过
![](../assets/10-marketData-exchangeRateManual.jpg)
