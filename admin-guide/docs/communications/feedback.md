## 10. 用户反馈处理

**操作路径**：左侧导航栏 → 「用户反馈」

用户反馈页面用于查看投资者提交的业务反馈与产品反馈，并支持查看完整内容和附件图片。

![](../assets/37-userFeedback-list.png)


### 10.1 反馈列表

| 字段 | 说明 |
|------|------|
| **用户名称** | 提交反馈的投资者 |
| **反馈类型** | 业务反馈 / 产品反馈 |
| **反馈内容** | 用户填写的具体反馈文字 |
| **图片数** | 用户上传的附件图片数量 |
| **提交时间** | 反馈提交时间 |
| **操作** | 查看详情 |

### 10.2 反馈处理流程

1. **筛选反馈**：可按反馈内容、姓名、电子邮件或手机号搜索，并选择「全部反馈 / 业务反馈 / 产品反馈」
2. **查看详情**：点击「查看详情」查看完整文字和附件图片
3. **分类处理**：
   - **业务反馈** → 转交业务团队处理
   - **产品反馈** → 转交产品团队评估
4. **跟进结果**：在内部流程记录处理意见，必要时通过客服或业务人员联系用户

> 💡 **建议**：定期汇总用户反馈，识别高频问题，推动产品和流程优化。
