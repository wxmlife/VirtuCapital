## 9. 消息模板管理

**操作路径**：左侧导航栏 → 「消息模板」

系统内置了多种业务场景的 App 消息中心模板，管理员可维护不同语言下的标题和正文。模板类型由系统代码定义，后台主要负责文案编辑、变量核对和草稿预览。
![](../assets/24-messageTemplate-list.jpg)

### 9.2 模板编辑

**操作步骤**：
1. 点击模板名称进入编辑页
2. 选择语言标签（繁体中文 / 简体中文 / 英文）
3. 修改站内消息标题和正文
4. 检查「可用变量」列表，确认必填变量已保留
5. 在 Payload JSON 中输入测试数据，点击「预览草稿」
6. 点击「储存」保存模板

> 💡 **变量说明**：模板中 `{变量名}` 的部分会在发送时自动替换为实际值。
