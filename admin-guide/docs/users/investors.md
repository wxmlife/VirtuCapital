## 3. 投资者管理

### 3.1 投资者列表

**操作路径**：左侧导航栏 → 「投资者」

使用列表上方的搜索框，可按手机号、姓名、电子邮件或 VC User ID 定位用户。搜索结果涉及资产和联系方式时，应确认命中的姓名、手机号及 VC User ID 属于同一人。

#### 表格字段说明

| 字段 | 说明 |
| --- | --- |
| **姓名 / VC User ID** | 用户显示名称、开户标记和平台用户编号 |
| **手机号** | 注册手机号 |
| **总资产** | 页面当前统计口径下的资产合计 |
| **成本** | 当前记录的持仓成本合计 |
| **盈亏** | 累计盈亏金额及比例 |
| **今日盈亏** | 当日盈亏金额及比例 |
| **角色** | 投资者、管理员或超级管理员 |
| **操作** | 当前账号获准执行的行级操作 |

### 3.2 投资者操作

点击目标行最右侧的「操作」按钮。菜单内容会随当前角色、目标用户状态和系统版本变化；只执行页面实际显示且已获得授权的操作。

### 3.3 查看详情

1. 先核对姓名、手机号和 VC User ID；
2. 打开「查看详情」；
3. 按详情页实际提供的区块查看基础资料、账户状态、资产或持仓、业务记录及操作留痕；
4. 需要调查单笔业务时，从详情页记录的标识跳转或前往「记录」「审计日志」继续核对；
5. 查看完成后返回列表，避免把上一位客户的资料误用于下一项操作。

:::warning 敏感资料
详情页可能包含联系资料、身份信息、资产和交易记录。只在业务需要范围内查看，不要复制到未授权的文档或聊天中。
:::

### 3.4 变更角色

角色变更会改变后台访问范围，应由具备该权限的授权人员执行。

1. 在列表中精确定位目标用户；
2. 打开行操作菜单并进入角色变更界面；
3. 核对当前角色、目标角色和用户标识；
4. 确认已有审批记录，再执行确认；
5. 变更后让用户重新登录，并在审计日志中核对记录。

### 3.5 不应推断的操作

如果当前行菜单没有显示编辑、停用或删除等操作，就表示当前账号或当前版本不提供该入口。不要依据旧版截图或旧流程执行替代操作；需要处理账户状态时，应通过组织批准的内部流程升级。
