## 0. How to Become an Administrator

> 1️⃣ Register as an **investor** in the **Virtu Capital client** using a Hong Kong mobile number, then bind a custom email address (for example, `name@virtu-capital.com`) and password. The email address currently does not need to be registered or verified in advance; email verification will be added later.
>
> 2️⃣ An administrator account changes the investor role to **administrator**.
>
> 3️⃣ A backend technician changes the investor role to **super administrator**.
