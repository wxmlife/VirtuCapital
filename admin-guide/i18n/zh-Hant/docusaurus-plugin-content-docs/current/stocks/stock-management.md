## 4. 股票管理

### 4.1 黃河賬戶持倉概覽

**操作路徑**：左側導航欄 → 「股票管理」

頂部展示平臺整體持倉情況：

| 指標 | 說明 |
|------|------|
| **持倉股票數** | 平臺管理的股票種類數量 |
| **黃河賬戶總持倉** | 平臺自有賬戶的總持倉市值 |
| **可分配持倉數** | 尚未分配給投資者的持倉數量 |
| **已分配持倉數** | 已分配給投資者的持倉數量 |
| **超分配股票** | 已分配數量超過總倉數的股票（風險指標） |
| **已管理股票數** | 當前正在管理的股票總數 |
| **總設定倉數** | 所有股票設定的總持倉數量 |
| **已分配倉數** | 已分配給投資者的倉數總和 |
| **涉及投資者** | 持有股票的投資者人數 |

> 🚨 **重點關注**：「超分配股票」表示分配異常，需立即覈查。
![](../assets/06-stockManage-accountPosition.jpg)


### 4.2 股票管理列表

#### 檢索功能

| 檢索條件 | 說明 |
|---------|------|
| **股票名稱** | 輸入股票中文/英文名稱 |
| **股票代碼** | 輸入股票代碼（如 00700） |
| **市場搜索** | 按市場篩選（港股/美股/A股） |

#### 表格字段說明

| 字段 | 說明 |
|------|------|
| **股票** | 股票名稱 |
| **市場** | 所屬市場（港股HK/美股US/A股CN） |
| **總倉數** | 該股票設定的總持倉數量 |
| **已分配倉數** | 已分配給投資者的持倉數量 |
| **剩餘倉數** | 總倉數 - 已分配倉數 |
| **投資者數** | 持有該股票的投資者人數 |
| **建立時間** | 該股票加入系統的時間 |
| **操作** | 編輯/刪除等操作 |

### 4.3 新增股票

**操作路徑**：股票管理頁 → 點擊「新增股票」按鈕
![](../assets/07-stockManage-addStock.jpg)

#### 步驟一：配置股票信息

| 字段 | 說明 | 必填 |
|------|------|------|
| **股票** | 搜索並選擇股票（支持名稱/代碼搜索） | ✅ |
| **股票總倉數** | 設定該股票的總持倉數量 | ✅ |
| **初始價格（成本價）** | 該股票的初始成本價格 | ✅ |

#### 步驟二：投資者分配

爲投資者分配持倉：

| 字段 | 說明 |
|------|------|
| **投資者** | 選擇要分配的投資者 |
| **持倉數** | 分配給該投資者的持倉數量 |
| **成本價** | 該投資者的持倉成本價 |
| **佔比** | 該投資者持倉佔總倉數的比例（自動計算） |
| **操作** | 刪除該分配行 |

> 💡 **提示**：可添加多行，爲多個投資者同時分配。

#### 步驟三：配置摘要

系統自動計算並展示：
- **股票總倉數**：設定的總持倉數
- **已分配倉數**：當前已分配的持倉總數
- **剩餘倉數**：總倉數 - 已分配倉數

> ⚠️ **校驗規則**：已分配倉數不能超過總倉數。
