##

**操作路徑**：左側導航欄 → 「股票管理」

### 持倉概覽與列表

頁面彙總持倉股票數、總設定倉數、已分配倉數、可分配倉數、涉及投資者及超分配股票。出現超分配時，應立即核對對應股票。

列表支援按股票名稱、股票代碼和市場搜尋。

| 欄位 | 說明 |
| --- | --- |
| **股票** | 股票名稱和代碼 |
| **市場** | 港股、美股或頁面支援的其他市場 |
| **總倉數** | 後台為該股票設定的總數量 |
| **已分配倉數** | 已分配給投資者的數量合計 |
| **剩餘倉數** | 總倉數減去已分配倉數 |
| **投資者數** | 目前持有該股票的投資者數量 |
| **建立時間** | 股票記錄建立時間 |
| **操作** | 目前角色可用的管理入口 |

![股票管理](../assets/V102/stocks-management.png)
:::warning
發現「超分配」時先停止新增分配，核對該股票的總倉數及每位投資者數量；\
不要透過新增一條股票記錄來掩蓋異常。
:::

### 新增股票與分配

點擊「新增股票」，按以下順序設定：

1. 按地區或股票代碼搜尋並選擇股票；
2. 填寫股票總數量和初始成本價；
3. 點擊「新增投資者」，為一個或多個投資者填寫分配數量與成本價；
4. 核對自動計算的分配佔比、已分配數量和可用持倉；
5. 確認設定摘要後建立股票。

![新增股票與投資者分配](../assets/V102/stocks-create-and-allocate.png)

| 驗證規則 | 說明 |
|----------|------|
| **投資者不可重複** | 同一股票不能重複新增同一投資者 |
| **數量不能超限** | 所有投資者的分配數量合計不得超過股票總數量 |
| **佔比自動計算** | 佔比按投資者數量 ÷ 股票總數量計算 |
| **可用持倉聯動** | 修改或刪除分配行後，可用持倉和摘要即時更新 |

### 完成分配

當已分配數量等於股票總數量時，頁面會顯示已全部分配，可用持倉為 0。此時仍應逐行檢查投資者、數量和成本價，再點擊建立。

![股票已全部分配](../assets/V102/stocks-allocation-complete.png)

> ⚠️ 初始成本價和投資者成本價會影響持倉成本顯示。建立前請依據實際交割數據核對，避免用估算值代替。

### 建立前核對

1. 股票代碼、名稱和市場相互一致；
2. 股票總數量與實際交割或持倉資料一致；
3. 投資者沒有選錯同名帳號，VC User ID 已核對；
4. 各行數量合計不超過總數量，成本價幣種正確；
5. 未分配數量符合業務預期；
6. 建立完成後回到列表檢查總倉數、已分配倉數和投資者數。

### 異常處理

- **搜尋不到股票**：先檢查市場和代碼格式，再確認市場數據是否已同步；
- **無法新增投資者**：確認用戶存在、狀態允許分配且沒有重複新增；
- **數量超限**：減少分配數量或先核實總倉數，不要繞過驗證；
- **建立後數據不一致**：停止繼續分配，記錄股票代碼與操作時間，並結合審計日誌排查。
