## 3. 投資者管理

### 3.1 投資者列表

**操作路徑**：左側導航欄 → 「投資者」

使用列表上方的搜尋框，可按手機號碼、姓名、電郵或 VC User ID 定位用戶。搜尋結果涉及資產和聯繫方式時，應確認命中的姓名、手機號碼及 VC User ID 屬於同一人。

#### 表格欄位說明

| 欄位 | 說明 |
| --- | --- |
| **姓名 / VC User ID** | 用戶顯示名稱、開戶標記和平台用戶編號 |
| **手機號碼** | 註冊手機號碼 |
| **總資產** | 頁面當前統計口徑下的資產合計 |
| **成本** | 當前記錄的持倉成本合計 |
| **盈虧** | 累計盈虧金額及比例 |
| **今日盈虧** | 當日盈虧金額及比例 |
| **角色** | 投資者、管理員或超級管理員 |
| **操作** | 當前帳號獲準執行的行級操作 |

### 3.2 投資者操作

點擊目標行最右側的「操作」按鈕。選單內容會隨當前角色、目標用戶狀態和系統版本變化；只執行頁面實際顯示且已獲得授權的操作。

### 3.3 查看詳情

1. 先核對姓名、手機號碼和 VC User ID；
2. 打開「查看詳情」；
3. 按詳情頁實際提供的區塊查看基礎資料、帳戶狀態、資產或持倉、業務記錄及操作留痕；
4. 需要調查單筆業務時，從詳情頁記錄的識別碼跳轉或前往「記錄」「審計日誌」繼續核對；
5. 查看完成後返回列表，避免把上一位客戶的資料誤用於下一項操作。

<!-- screenshot-slot: investors-detail; status: placeholder -->
> 📷 **截圖待補：投資者詳情頁及主要資料區。**

:::warning 敏感資料
詳情頁可能包含聯繫資料、身份資訊、資產和交易記錄。只在業務需要範圍內查看，不要複製到未授權的文檔或聊天中。
:::

### 3.4 變更角色

角色變更會改變後台訪問範圍，應由具備該權限的授權人員執行。

1. 在列表中精確定位目標用戶；
2. 打開行操作選單並進入角色變更介面；
3. 核對當前角色、目標角色和用戶識別碼；
4. 確認已有審核記錄，再執行確認；
5. 變更後讓用戶重新登入，並在審計日誌中核對記錄。

<!-- screenshot-slot: investors-role-change-dialog; status: placeholder -->
> 📷 **截圖待補：角色變更確認介面。**

> ⚠️ 普通管理員不得自行提升權限。僅查看彈窗時應點擊取消或關閉，不能把演示操作確認到真實帳號。

### 3.5 不應推斷的操作

如果當前行選單沒有顯示編輯、停用或刪除等操作，就表示當前帳號或當前版本不提供該入口。不要依據舊版截圖或舊流程執行替代操作；需要處理帳戶狀態時，應透過組織批准的內部流程升級。
