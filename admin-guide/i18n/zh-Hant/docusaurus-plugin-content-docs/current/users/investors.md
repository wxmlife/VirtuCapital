## 3. 投資者管理

### 3.1 投資者列表

**操作路徑**：左側導航欄 → 「投資者」

#### 檢索功能

支持多維度檢索投資者：
- **手機號**：輸入完整或部分手機號
- **姓名**：輸入投資者姓名
- **電子郵件**：輸入註冊郵箱

> 🔍 **技巧**：支持模糊搜索，輸入部分信息即可匹配。

#### 表格字段說明

| 字段 | 說明 |
|------|------|
| **姓名** | 投資者真實姓名 |
| **手機號** | 註冊手機號 |
| **電子郵件** | 註冊郵箱地址 |
| **總資產** | 該投資者的股票市值 + 現金餘額 |
| **成本** | 該投資者的歷史投入成本 |
| **盈虧** | 累計盈虧金額及漲跌幅百分比 |
| **今日盈虧** | 當日盈虧金額及漲跌幅百分比 |
| **角色** | 用戶權限級別 |
| **操作** | 可執行的管理操作 |

#### 角色類型

| 角色 | 權限範圍 |
|------|---------|
| **投資者** | 普通用戶，可進行交易、查看持倉等 |
| **管理員** | 可管理投資者、審覈記錄、查看數據 |
| **超級管理員** | 擁有全部權限，包括系統設定、角色變更等 |

### 3.2 投資者操作

點擊「操作」列的按鈕，可執行以下操作：

#### 查看詳情
- 查看該投資者的完整資料
- 包括：個人信息、持倉明細、交易記錄、資金流水等

#### 編輯用戶
- 修改投資者的基本信息（姓名、聯繫方式等）
- 修改投資者的賬戶設置

#### 變更角色
- 將投資者升級爲管理員
- 將管理員降級爲投資者
- **超級管理員**才能執行此操作

> ⚠️ **風險提示**：變更角色前請確認用戶身份，避免權限濫用。

#### 刪除用戶
- 永久刪除該投資者賬戶
- **此操作不可逆**，刪除前系統會要求二次確認
- 刪除前請確認已完成必要的數據覈對與業務留痕
