## 角色權限與操作邊界

以下兩張表彙總投資者、管理員和超級管理員的操作範圍。管理員處理業務時，先確認自己是發起申請、進行初審，還是執行設定；標註「需超級管理員審核」的操作，完成後必須等待複審。

![帳戶與資產操作權限表](../assets/V102/permissions-account-assets.png)

![客戶、股票、市場與系統設定權限表](../assets/V102/permissions-customer-system.png)

實際權限仍會受到組織授權、帳戶狀態和部署版本影響；頁面權限與圖片不一致時，以更嚴格的邊界為準。

### 角色變更

1. 使用姓名、手機號碼和 VC User ID 精確定位用戶；
2. 核對當前角色、目標角色和審核依據；
3. 只授予完成崗位職責所需的最低角色；
4. 變更後要求用戶重新登入，並驗證可見選單；
5. 在審計日誌中核對操作人、目標用戶、時間和結果。

:::warning 高風險操作
角色提升、系統設定、匯率和資金或持倉相關終審不得由同一人繞過審核鏈完成。頁面存在按鈕不等於當前人員已獲得業務授權。
:::

### 審計與追溯

角色變更、審核和設定操作完成後，應在審計日誌中核對記錄。使用操作人、目標用戶、資源 ID、結果和時間範圍縮小查詢；失敗記錄也應保留並調查原因。

![審計日誌列表與篩選條件](../assets/V102/audit-log-list.jpg)

### 權限回收

出現崗位變更、離職、帳號共用、異常登入或授權到期時，應立即透過組織審核流程降權或撤銷訪問，並檢查近期審計日誌。不要僅透過修改顯示名稱來代替權限回收。

### 聯繫支援

| 問題類型 | 聯繫方式 |
| --- | --- |
| 技術故障 | tech-support@virtucapital.com |
| 業務諮詢 | operations@virtucapital.com |
| 緊急事件 | 24 小時熱線：+852-xxxx-xxxx |

提交問題時建議提供：

- 發生時間、環境和當前路由；
- 當前帳號角色（不要提供密碼或驗證碼）；
- 可復現步驟與頁面錯誤文字；
- 相關業務記錄 ID 或審計日誌 ID；
- 已脫敏的截圖或日誌。
