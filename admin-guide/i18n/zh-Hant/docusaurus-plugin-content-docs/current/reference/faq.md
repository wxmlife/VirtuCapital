## 11. 常見問題 FAQ

### Q1：為什麼我的審核操作沒有立即生效？

**A**：匯率、系統設定及部分高風險業務需要提交審核。普通管理員完成初審或提交後，記錄可能進入「待超級管理員審核」；在終審通過前，當前生效值不會改變。請在「記錄」中按狀態查找，並核對詳情和操作日誌。

### Q2：如何處理「超分配股票」？

**A**：「超分配」表示已分配數量超過後台設定的總倉數。停止繼續分配，核對股票代碼、總倉數、各投資者數量及最近審計記錄。確認原因和批准的修正方案後再處理，不能透過新增重複股票來抵消異常。

### Q3：投資者忘記密碼怎麼辦？

**A**：管理員不能查看用戶密碼，也不應代用戶設定或收集密碼。請引導用戶使用客戶端當前提供的帳號恢復流程；無法恢復時，透過組織授權的身份核驗與支援流程處理。

### Q4：系統出現異常數據怎麼辦？

**A**：
1. 停止重複提交、審核或儲存；
2. 記錄發生時間、環境、頁面路由和業務記錄 ID；
3. 查看審計日誌，確認最近是否有相關變更；
4. 涉及價格或資產時檢查市場數據同步和匯率模式；
5. 透過內部支援流程提交已脫敏資訊。

### Q5：如何修改自己的管理員資訊？

**A**：當前後台可直接使用語言和主題控制，並可安全登出。若頁面沒有個人資料或密碼修改入口，不要依據舊手冊猜測；請按組織的帳號管理流程申請變更。

### Q6：為什麼有些記錄顯示「待超級管理員審核」？

**A**：該狀態表示管理員階段已經完成，但流程仍要求具備終審權限的人員複核。常見於系統設定、人工匯率及頁面標記為需要終審的資金或持倉業務。具體以記錄詳情顯示的待辦和生命週期為準。

### Q7：如何查看某個投資者的所有操作記錄？

**A**：
1. 在「投資者」中按姓名、手機號碼、電郵或 VC User ID 精確定位；
2. 打開詳情，查看頁面提供的帳戶、資產和業務記錄區塊；
3. 需要完整後台操作留痕時，前往「審計日誌」，使用目標用戶 ID 和時間範圍檢索。

### Q8：企業開戶草稿在哪裏繼續？

**A**：進入「客戶管理 → 企業用戶」，找到資料狀態為草稿的企業記錄，在操作選單選擇「繼續開戶」。先檢查當前階段和已上傳文件，再繼續填寫；不要為同一企業重複建立草稿。

### Q9：訊息模板預覽仍顯示變數怎麼辦？

**A**：檢查 Payload JSON 的欄位名稱是否與「可用變數」完全一致，必填變數是否都有測試值，以及 JSON 是否有效。預覽通過前不要儲存正式環境文案；預覽不會發送真實訊息。

### Q10：市場數據同步失敗怎麼辦？

**A**：先點擊「重新整理」確認最新狀態，再查看對應市場的上次同步時間、觸發來源和錯誤狀態。不要同時重複觸發多個同步任務；中國 A 股等顯示「不可同步」的市場無需強制操作。

### Q11：頁面跳轉後出現 `ChunkLoadError` 或紅色錯誤遮罩怎麼辦？

**A**：先停止當前操作並重新整理頁面；確認沒有重複提交後重新登入。若仍出現，記錄出錯前後的路由、時間、環境和完整錯誤文字，透過內部技術支援流程上報。錯誤消失前不要繼續審核、儲存或提交表單。
