## 11. 常見問題 FAQ

### Q1：爲什麼我的審覈操作沒有立即生效？

**A**：系統設定和關鍵業務操作（如匯率修改、手續費調整）需要**提交審覈**並由超級管理員審批後才能生效。請在「記錄」頁面查看審覈進度。

### Q2：如何處理「超分配股票」？

**A**：「超分配股票」表示已分配給投資者的持倉超過了總倉數，屬於異常情況。處理步驟：
1. 進入「股票管理」查看超分配詳情
2. 覈查各投資者的持倉數據
3. 聯繫相關投資者協調調整
4. 修正分配數據，確保總倉數 ≥ 已分配倉數

### Q3：投資者忘記密碼怎麼辦？

**A**：管理員無法直接查看或修改投資者密碼。請引導投資者：
1. 在登錄頁點擊「忘記密碼」
2. 通過註冊郵箱或手機號重置密碼
3. 如無法自助重置，可在「投資者管理」中核實身份後協助處理

### Q4：系統出現異常數據怎麼辦？

**A**：
1. 首先查看「審計日誌」，確認是否有異常操作
2. 檢查「市場數據」同步狀態，確認行情數據正常
3. 如無法自行解決，聯繫技術團隊並提供：
   - 問題描述
   - 截圖
   - 相關記錄ID
   - 審計日誌中的操作記錄

### Q5：如何修改自己的管理員信息？

**A**：點擊頁面右上角的管理員名稱，進入個人中心：
- 修改顯示名稱
- 修改登錄密碼
- 配置雙因素認證（2FA）

### Q6：爲什麼有些記錄顯示「待超級管理員審覈」？

**A**：以下操作需要超級管理員終審：
- 大額資金操作（超過設定閾值）
- 系統設定修改
- 角色變更
- 用戶刪除
- 人工編輯的匯率

普通管理員初審通過後，會自動流轉到超級管理員終審。

### Q7：如何查看某個投資者的所有操作記錄？

**A**：
1. 進入「投資者管理」
2. 找到該投資者，點擊「查看詳情」
3. 在詳情頁查看「交易記錄」「資金流水」「操作日誌」等標籤頁
