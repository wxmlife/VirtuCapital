## 2. 儀表盤概覽

儀表盤是管理員登錄後的默認首頁，提供平臺核心數據的**實時監控**。

### 2.1 市場概覽卡片

| 指標 | 說明 |
|------|------|
| **總投資者數** | 平臺註冊投資者的總人數 |
| **總資產（HKD）** | 所有投資者資產的總和（按當前匯率折算爲港幣） |
| **股票價值（HKD）** | 所有投資者持有股票的市值總和 |
| ├─ W/L 24小時盈虧 | 最近24小時內股票市值的盈虧變化 |
| **現金** | 各幣種的現金餘額彙總 |
| ├─ HKD | 港幣現金餘額 |
| ├─ USD | 美元現金餘額 |
| └─ USDT | USDT 餘額 |

> 💡 **用途**：快速掌握平臺整體資產規模和資金分佈情況。
> 
![](../assets/02-post-login.jpg)


### 2.2 黃河賬戶

顯示平臺自有資金的賬戶餘額：
- **美元餘額**
- **港元餘額**

> ⚠️ **注意**：黃河賬戶用於平臺資金調配，操作需謹慎。

### 2.3 快捷操作

提供常用功能的快速入口：
1. **管理投資者** → 跳轉至投資者列表頁
2. **管理股票分配** → 跳轉至股票管理頁
3. **查看市場數據** → 跳轉至市場數據頁
4. **配置消息模板** → 跳轉至消息模板頁

### 2.4 系統信息

| 項目 | 說明 |
|------|------|
| 應用程序 | 系統名稱（Virtu Capital） |
| 版本 | 當前系統版本號 |
| 環境 | 運行環境（生產環境/測試環境） |
