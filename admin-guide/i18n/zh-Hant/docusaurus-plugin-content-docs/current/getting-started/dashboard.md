## 2. 儀表盤概覽

儀表盤是管理員登入後的概覽頁，用於快速判斷平台資產、帳戶餘額和系統狀態。數值的統計口徑、幣種和更新時間以頁面當前標註為準。

### 2.1 市場概覽卡片

| 指標 | 說明 |
| --- | --- |
| **總投資者數** | 當前納入統計的投資者數量 |
| **總資產（HKD）** | 按頁面匯率口徑折算後的資產彙總 |
| **股票價值（HKD）** | 投資者股票市值彙總 |
| **現金** | HKD、USD、USDT 等幣種餘額彙總 |

卡片用於發現明顯異常，不應代替業務明細或會計對賬。數值異常時，依次核對市場數據匯率、股票行情、投資者持倉和資金記錄。

### 2.2 黃河帳戶

該區域顯示平台帳戶的可見幣種餘額，例如美元和港元。餘額僅用於查看和核對；實際調撥、入賬或出賬應從對應業務流程執行。

> ⚠️ 儀表盤餘額與業務記錄不一致時，不要透過重複審核或重複錄入來「修正」顯示。先定位原始記錄和審計日誌。

### 2.3 快捷操作

快捷卡片可進入投資者、股票管理、市場數據和訊息模板等常用頁面。點擊後應確認頁面標題與目標一致，再執行操作；瀏覽器返回不會自動撤銷已經儲存或提交的內容。

### 2.4 系統資訊

| 項目 | 說明 |
| --- | --- |
| **應用程式** | 當前後台應用名稱 |
| **版本** | 當前部署版本，用於故障定位 |
| **環境** | 當前運行環境；測試與正式環境的數據不可混用 |

### 2.5 日常巡檢建議

1. 確認總資產、股票價值和現金沒有無法解釋的突變；
2. 檢查平台帳戶餘額與最近完成的資金記錄是否一致；
3. 查看「記錄」選單是否出現待辦紅點；
4. 檢查市場數據的最近同步狀態；
5. 報告問題時附上頁面、時間、環境和版本，但不要附帶未脫敏的客戶資料。
