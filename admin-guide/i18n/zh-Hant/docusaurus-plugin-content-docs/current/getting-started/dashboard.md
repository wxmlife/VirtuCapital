##

儀表盤是管理員登入後的預設首頁，提供平台核心數據的 **即時監控**。

### 市場概覽卡片

| 指標 | 說明 |
| --- | --- |
| 總投資者數 | 平台註冊投資者的總人數 |
| 總資產（HKD） | 所有投資者資產的總和（按目前匯率折算為港幣） |
| 股票價值（HKD） | 所有投資者持有股票的市值總和 |
| ├── W/L 24小時盈虧 | 最近24小時內股票市值的盈虧變化 |
| 現金 | 各幣種的現金餘額彙總 |
| ├── HKD | 港幣現金餘額 |
| ├── USD | 美元現金餘額 |
| └── USDT | USDT 餘額 |

:::tip 用途
快速掌握平台整體資產規模和資金分佈情況。
:::

![儀表盤](../assets/V102/FirstPage.png)

### 黃河帳戶

顯示平台帳戶的可見幣種餘額。
- 美元餘額
- 港元餘額\
餘額用於查看和核對；實際調撥、入賬或出賬應從對應業務流程執行。

### 快捷操作

快捷卡片可進入投資者、股票管理、市場數據和訊息模板等常用頁面。點擊後應確認頁面標題與目標一致，再執行操作；瀏覽器返回不會自動撤銷已經儲存或提交的內容。

### 系統資訊

| 項目 | 說明 |
| --- | --- |
| **應用程式** | 目前後台應用名稱 |
| **版本** | 目前部署版本，用於故障定位 |
| **環境** | 目前執行環境；測試與正式環境的數據不可混用 |

![系統資訊](../assets/V102/dashboard-information.png)

### 日常巡檢建議

1. 確認總資產、股票價值和現金沒有無法解釋的突變；
2. 檢查平台帳戶餘額與最近完成的資金記錄是否一致；
3. 查看「記錄」選單是否出現待辦紅點；
4. 檢查市場數據的最近同步狀態；
5. 報告問題時附上頁面、時間、環境和版本，但不要附帶未脫敏的客戶資料。
