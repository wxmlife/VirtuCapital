## 0. 如何成為管理員

<div className="admin-step-card">
  <div className="admin-step-header">
    <span className="admin-step-number">1</span>
    <div className="admin-step-title">註冊投資者</div>
  </div>
  <p>在 <strong>Virtu Capital 客戶端</strong>使用香港手機號碼註冊為<strong>投資者</strong>，綁定自訂電郵（例如 <code>name@virtu-capital.com</code>）和密碼。目前電郵無需預先註冊或驗證，後續會加入電郵驗證。</p>
</div>

<div className="admin-step-card">
  <div className="admin-step-header">
    <span className="admin-step-number">2</span>
    <div className="admin-step-title">變更為管理員</div>
  </div>
  <p>由管理員帳號將投資者角色更改為<strong>管理員</strong>。</p>
</div>

<div className="admin-step-card">
  <div className="admin-step-header">
    <span className="admin-step-number">3</span>
    <div className="admin-step-title">變更為超級管理員</div>
  </div>
  <p>由後端技術人員將投資者角色更改為<strong>超級管理員</strong>。</p>
</div>
