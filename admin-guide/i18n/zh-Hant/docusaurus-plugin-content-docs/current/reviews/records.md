## 6. 記錄審核

**操作路徑**：左側導航欄 → 「記錄」

記錄頁統一展示訂單、入金、出金、換匯、股票轉讓和轉倉等業務。選單出現紅點時，表示存在待處理記錄。

![待審核記錄列表](../assets/V102/records-pending-list.jpg)

### 6.1 檢索記錄

| 條件 | 說明 |
|------|------|
| **記錄類型** | 全部、訂單、入金、出金、換匯、股票轉讓、轉倉、後台操作等 |
| **投資者** | 按姓名、電郵、手機號碼或投資者 ID 搜尋 |
| **審核狀態** | 無需審核、待審核、待超級管理員審核、已通過、已拒絕、已取消 |
| **股票** | 按代碼、Ticker、Stock Key 或名稱搜尋 |

點擊「套用篩選」執行查詢，「重設」清空條件，「重新整理」獲取最新狀態。列表展示投資者、股票、操作類型、待辦事項、數量、金額、時間、審核狀態、業務狀態和詳情入口，並支援分頁。

### 6.2 通用審核原則

1. 打開詳情，核對申請人、金額或數量、附件及關聯帳戶；
2. 檢查凍結資金或持倉是否足夠，手續費是否正確；
3. 對照生命週期、關聯交易和操作日誌確認狀態一致；
4. 審核通過前再次確認關鍵數據；拒絕時填寫明確原因；
5. 出金和轉倉等高風險操作在管理員通過後，仍需超級管理員二次審核。

### 6.3 股票轉入審核

詳情頁顯示轉倉單號、操作類型、業務與審核狀態、投資者、目標券商、原始券商、來源帳戶、結算參與者代碼、轉入股票及數量、附件、生命週期、操作日誌和審核入口。

![股票轉入詳情](../assets/V102/records-inbound-transfer-detail.jpg)

核對原券商轉出確認、來源帳戶、目標券商、股票代碼、數量和申請文件是否一致。附件或資料不完整時不要通過；填寫明確審核意見後執行通過或拒絕，並繼續檢查生命週期是否進入下一狀態。

### 6.4 股票轉出審核

詳情頁重點包括接收券商、接收帳戶、聯絡人、轉出股票與數量、凍結持倉、手續費、市值、申請附件、生命週期、關聯資金記錄和操作日誌。

![股票轉出詳情](../assets/V102/records-outbound-transfer-detail.jpg)

審核時確認接收資料完整、凍結數量足夠、費用正確，且申請表、簽名和券商結單與申請一致。管理員通過後按流程等待超級管理員複核；最終狀態應與持倉釋放、關聯資金記錄和生命週期同步。

### 6.5 股票轉讓審核

股票轉讓詳情展示轉出方與接收方、股票、數量、協定價格、協定金額、幣種、BSN、凍結持倉、關聯交易和操作日誌。

![股票轉讓詳情](../assets/V102/records-stock-transfer-detail.jpg)

重點核對雙方身份、數量、價格及金額計算，確認轉出方持倉已正確凍結，且不存在重複或衝突交易，再執行通過或拒絕。

### 6.6 其他記錄

- **現金入金**：核對入金方式、幣種、金額、手續費、付款帳戶與憑證；通過後核對關聯入帳流水及餘額變化；
- **現金出金**：核對收款帳戶、可用餘額、凍結金額、手續費和附件；管理員初審後按流程等待終審；
- **訂單、買賣、換匯**：核對可用資金或持倉、價格、手續費和市場狀態；
- **資料變更**：比較變更前後資訊，敏感資料需額外驗證；
- **後台操作**：核對操作人、目標資源、變更摘要和執行結果。

典型審核狀態為：已提交 → 待審核 → 管理員已通過 → 待超級管理員審核 → 已完成；任一審核環節均可能因資料不符轉為已拒絕，用戶主動取消則顯示已取消。

### 6.7 審核後的複核

1. 重新整理記錄並確認審核狀態已經更新；
2. 核對業務狀態、資金或持倉狀態與審核結果一致；
3. 檢查關聯交易、生命週期和操作日誌沒有停留在中間狀態；
4. 對高風險業務等待終審，不要重複點擊審核按鈕；
5. 狀態不一致時停止後續操作，並使用記錄 ID 到審計日誌中排查。
