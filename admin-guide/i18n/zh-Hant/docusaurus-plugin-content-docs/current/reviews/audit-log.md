##

**操作路徑**：左側導航欄 → 「審計日誌」

審計日誌記錄管理員對用戶、交易、股票和系統設定等資源執行的操作，用於安全審計和問題追溯。

![審計日誌列表與篩選條件](../assets/V102/audit-log-list.jpg)

### 查詢日誌

可組合使用以下條件：

| 條件 | 說明 |
|------|------|
| **關鍵字** | 搜尋操作名稱或摘要 |
| **操作類型** | 建立、修改、刪除、審核等 |
| **結果** | 成功或失敗 |
| **資源類型 / 資源 ID** | 定位被操作的業務資源 |
| **管理員用戶 ID** | 定位操作執行人 |
| **目標用戶 ID** | 定位受影響用戶 |
| **開始時間 / 結束時間** | 限定操作發生的時間範圍 |

設定條件後執行搜尋；需要查看剛發生的操作時，點擊「重新整理」再次取得數據。

### 日誌欄位與詳情

列表顯示時間、操作、管理員、目標用戶、資源類型與 ID、結果、來源 IP、摘要及詳情入口。點擊「查看詳情」可核對請求參數、變更內容和執行結果等完整資訊。

排查問題時建議按以下順序縮小範圍：

1. 先用時間範圍和結果定位異常批次；
2. 再用管理員 ID、目標用戶 ID 或資源 ID 找到具體記錄；
3. 檢查來源 IP、操作摘要和詳情，確認誰在何時對什麼資源執行了什麼操作；
4. 使用分頁繼續查看同一時間段的其他記錄。
