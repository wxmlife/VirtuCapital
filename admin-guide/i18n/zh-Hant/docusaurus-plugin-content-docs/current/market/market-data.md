## 市場數據管理

**操作路徑**：左側導航欄 → 「市場數據」

市場數據頁用於管理業務生效匯率，並查看中國 A 股、港股和美股的數據同步狀態。頁面右上角提供「強制重新同步」「同步全部」和「重新整理」操作；單個市場也可獨立同步。

### 匯率啟用模式

管理員可選擇客戶端資產換算和貨幣兌換使用哪套匯率：

| 模式 | 說明 |
|------|------|
| **市場匯率** | 使用 HKAB 自動同步的匯率快照 |
| **手動匯率** | 使用後台錄入的業務匯率 |

切換模式後點擊「提交審核」，超級管理員審核通過後才會生效。頁面同時顯示當前啟用模式、數據來源、匯率日期和最近同步時間。

![市場匯率模式與市場同步狀態](../assets/V102/market-data-market-rate.jpg)

### 匯率維護

系統支援以下六組匯率：

| 匯率對 | 匯率對 |
|--------|--------|
| 1 HKD → USD | 1 USD → HKD |
| 1 HKD → USDT | 1 USD → USDT |
| 1 USDT → HKD | 1 USDT → USD |

在市場匯率模式下，可點擊「同步市場匯率」獲取最新快照。在手動匯率模式下，填寫各匯率數值後提交審核；審核通過前不會影響當前業務匯率。

![手動匯率錄入與提交審核](../assets/V102/market-data-manual-rate.jpg)

### 股市數據同步

各市場卡片展示：

| 欄位 | 說明 |
|------|------|
| **交易所 / 股票 / ETF / 指數** | 當前已同步的數據量 |
| **同步狀態** | 成功、失敗或不可同步 |
| **上次同步 / 耗時** | 最近任務的時間與耗時 |
| **觸發來源** | API、計劃任務或後台手動觸發 |
| **下次計劃 / 計劃識別碼** | 自動同步計劃資訊 |

- 「同步」僅同步對應市場；
- 「同步全部」依次同步所有受支援市場；
- 「強制重新同步」用於需要忽略已有狀態、重新拉取全部數據的場景；
- 當前中國 A 股卡片顯示「不可同步」時，按鈕不可用，無需重複嘗試。

> ⚠️ 強制同步可能耗時較長。執行前確認沒有其他同步任務正在運行，完成後使用「重新整理」查看最新狀態。
