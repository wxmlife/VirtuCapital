Virtu Capital 转仓服务协议

版本号： V1.0.0
生效日期： 2026年8月3日
最近更新日期： 2026年8月3日

重要提示
本协议具有法律约束力。客户在 Virtu Capital 应用程序、网站或其他指定渠道勾选“我已阅读并同意”、提交转仓申请、签署转仓申请表或以其他方式确认接受本协议，即表示客户已阅读、理解并同意本协议全部内容。客户尤其应注意有关资料授权、资产冻结、费用、处理时限、申请撤销、第三方处理、责任限制及争议解决的条款。

一、协议主体与适用范围​

  1. 本《转仓服务协议》（以下简称“本协议”）由以下双方订立：
    • 服务提供方： Virtu Capital Finance Limited（以下简称“Virtu Capital”或“本公司”）；
    • 客户： 已在 Virtu Capital 开立并维持有效账户、申请使用转仓服务的个人或机构客户（以下简称“客户”或“您”）。
  2. 本协议适用于客户通过本公司将证券从其他券商或托管机构转入 Virtu Capital 账户（“转入”），或从 Virtu Capital 账户转至其他券商或托管机构（“转出”）的服务，合称“转仓服务”。
  3. 本协议是客户与本公司之间现有客户协议、账户条款、风险披露声明、APP 所示收费说明、隐私政策及其他适用文件的组成部分。就转仓服务的特定事项，本协议优先；其他事项以客户协议及相关专项条款为准；任何情况下均以适用法律、监管要求及相关交易、托管或结算规则为准。
  4. 本协议不适用于 Virtu Capital 客户之间的平台内股票转让、证券买卖、现金转账、融资或其他未明确列入转仓服务的事项。

二、定义​

除文意另有所指外：

  1. **“证券”**指本公司不时接纳办理转仓的股票及其他投资产品；
  2. **“转出机构”**指在转入申请中向 Virtu Capital 交付证券的券商、托管机构或其他金融机构；
  3. **“接收机构”**指在转出申请中接收证券的券商、托管机构或其他金融机构；
  4. **“第三方机构”**包括转出机构、接收机构、托管人、代理人、交易所、结算机构、存管机构及为完成转仓而参与的其他服务提供者；
  5. **“工作日”**指除星期六、星期日及奥克兰公众假期以外，新西兰奥克兰的注册银行通常营业的日期；涉及境外市场或第三方机构时，相关市场或机构所在地的营业日亦可能影响处理时间；
  6. **“CCASS”指香港中央结算系统；“DTC”**指美国存托信托公司或其相关结算系统。

三、服务资格与基本条件​

  1. 客户申请转仓时必须：
    • 已完成本公司要求的开户、身份核实、客户尽职调查及持续审查；
    • 账户处于正常状态，且不存在限制交易、冻结、调查、欠款或其他可能妨碍转仓的情形；
    • 对拟转仓证券拥有合法、完整且可处分的权益，并有权发出转仓指示；
    • 确保转出机构账户、Virtu Capital 账户及接收机构账户的持有人资料一致，除非本公司事先书面接受其他安排；
    • 满足适用法律、监管规定、市场规则及第三方机构的要求。
  2. 本公司目前仅处理其支持市场和证券范围内的转仓申请。是否支持某一证券、市场、账户类型或转仓方式，以申请页面、本公司通知及实际审核结果为准。
  3. 当前标准流程仅支持整数股转仓，不支持碎股；转仓仅处理证券，不处理现金。若本公司日后支持其他安排，以届时公布的规则为准。
  4. 本公司可基于合规、风险管理、运营能力、第三方要求、证券状态或其他合理原因，拒绝、暂停、拆分或要求修改任何转仓申请。

四、客户申请与授权​

  1. 客户应按照本公司指定流程提交转仓申请，并提供完整、真实、准确、有效且最新的资料，包括但不限于：
    • 客户姓名或机构名称、Virtu Capital 用户编号（VC UID）及账户资料；
    • 转仓方向、证券市场、证券名称、证券代码及数量；
    • 转出机构或接收机构的完整名称、CCASS/DTC 编号或其他结算编号；
    • 客户在相关机构的账户类型、账户姓名及账户号码；
    • 相关机构的联系人、联系电话及电子邮箱；
    • 已签署的转仓申请表、近期账户结单及本公司或第三方机构要求的其他证明文件。
  2. 客户确认并授权本公司：
    • 依照客户提交的申请及本协议采取完成转仓所合理需要的行动；
    • 向第三方机构发送、核实、更正或补充转仓指示，并与其沟通处理进度；
    • 为身份核实、合规审查、资产核对、费用结算、争议处理及完成转仓之目的，收集、使用、存储及披露客户资料；
    • 在合理需要时要求客户重新签署文件、补交资料或以其他方式确认指示。
  3. 客户通过电子方式签署、勾选确认、输入验证码或提交申请，具有与客户亲笔签署相同的效力，但适用法律另有强制规定的除外。
  4. 客户应同时按照转出机构或接收机构的要求提交匹配申请。两边申请中的账户姓名、账户号码、证券代码及数量等资料不一致，可能导致申请退回、延误或失败。
  5. 本公司没有义务核实客户指示的商业目的、税务后果或是否最符合客户利益，也不就转仓本身提供投资、法律或税务建议。

五、转入服务​

  1. 客户申请将证券转入 Virtu Capital 时，应确保转出机构已收到相匹配的转出指示，并及时完成转出机构要求的全部手续。
  2. 本公司收到申请后可进行初审、复审、券商对账、清算核对及其他必要程序。申请状态显示为“已提交”“处理中”或类似字样，仅表示本公司已收到或正在处理申请，不表示证券必然能够转入或已记入客户账户。
  3. 证券仅在本公司或其指定托管人确认实际收到、完成核对并记入客户账户后，才视为转入完成。客户在证券正式到账及显示为可交易前，不应假定其可供出售、转出、质押或作其他处分。
  4. 客户应自行核对转入证券的名称、代码、数量及成本资料。若成本价、买入日期或其他历史资料未随证券一并传送，客户应按本公司要求补交证明。本公司可在资料不足或尚待核实时暂不显示有关资料；任何成本资料仅作记录及参考用途，客户应自行保存原始交易记录并承担税务申报责任。

六、转出服务​

  1. 客户申请将证券转出 Virtu Capital 时，必须在账户中持有足够且可转出的证券，并维持足够可用资金支付转仓费用、第三方费用、税费及其他应付款项。
  2. 客户提交转出申请后，本公司可冻结或限制处分拟转出的证券，并可冻结或扣取预计费用。冻结期间，客户不得出售、重复转出、质押或以其他方式处分相关证券。
  3. 申请页面显示的费用、资产市值或其他金额可能仅为估算。实际费用以本公司最终核算及第三方机构实际收取为准。
  4. 如客户账户资金不足，本公司可暂停或拒绝执行申请、要求客户补足资金，或在客户协议及适用法律允许的范围内从客户账户可用余额中扣款。本公司不会仅为支付转仓费用而代客户出售证券，除非客户另行发出有效指示或客户协议明确授权。
  5. 证券从客户账户扣减、由第三方机构接收并完成相应结算后，方视为转出完成。接收机构何时将证券记入客户账户，由接收机构决定，本公司无法保证。

七、费用、税项及其他成本​

  1. 转仓服务是否收费、适用的费用项目、金额、币种、扣取时间及其他条件，以客户提交申请时 APP 展示的要求、收费说明或操作指引为准。本协议不表示本公司必然收取转仓服务费。
  2. 第三方机构可能另行收取托管费、结算费、转手费、代理费、税费或其他费用。相关费用的承担及处理，以 APP 展示的要求、操作指引及第三方机构的实际收费为准。
  3. 如客户提交申请时 APP 显示需要支付或预留相关费用，客户应确保账户内有足够可用资金。预计费用与最终实际费用可能存在差异。
  4. 如发生费用退还，适用条件、金额、方式及时间以 APP 展示的要求、操作指引和实际处理结果为准。
  5. 因汇率换算、银行收费或税务责任产生的成本，由相关责任方按照适用法律、APP 指引及实际处理情况承担。客户应在需要时自行咨询专业顾问。

八、处理时间与第三方依赖​

  1. 在资料齐全、双方指示匹配且不存在异常情况下，转仓通常预计需要 5–10 个工作日。该时间仅为一般估计，并非承诺或保证。
  2. 实际完成时间可能受第三方机构、结算系统、市场假期、公司行动、停牌、证券限制、资料补充、监管审查、系统故障、不可抗力或其他超出本公司合理控制范围的事项影响。
  3. 本公司可分批处理多只证券的转仓申请。部分证券已完成不代表其余证券必然能够完成。
  4. 客户应通过本公司指定渠道查看进度并及时回应补件或确认要求。客户延迟回应造成的后果由客户承担。

九、公司行动与交易风险​

  1. 转仓期间可能发生派息、供股、配股、合股、拆股、收购、投票、认购、赎回或其他公司行动。相关权益的确认、分配及到账时间可能因登记日、结算状态及第三方处理而延迟或调整。
  2. 客户理解转仓期间相关证券可能无法交易，市场价格可能波动，客户可能因此错失买卖机会或蒙受损失。
  3. 如转仓期间出现公司行动，本公司将按其记录、第三方机构提供的资料、适用市场规则及实际收到的权益进行处理。客户应及时提供必要指示；未按时提供指示可能导致权利失效。
  4. 客户应在转仓前自行评估未完成交易、卖空责任、保证金要求、留置权、质押、公司行动及税务影响。

十、撤销、修改、拒绝与终止​

  1. 客户提交申请后，如页面提供撤销功能，可在本公司尚未执行或向第三方发出不可撤回指示前申请撤销。撤销申请并不保证成功。
  2. 申请进入对账、交收、清算划转或其他不可逆阶段后，本公司可拒绝撤销或修改。
  3. 撤销成功后，证券或资金的解冻仍需合理处理时间。客户应待系统确认可用后再进行交易或重新申请。
  4. 出现下列情形之一时，本公司可拒绝、暂停、取消或终止申请：
    • 资料不完整、不准确、不一致、过期或疑似虚假；
    • 客户未及时补件、确认或支付费用；
    • 证券数量不足、不可转让、受限制、被冻结、被质押或涉及争议；
    • 客户账户异常、受限制、被调查或存在欠款；
    • 第三方机构拒绝、无法匹配或未在合理时间内回应；
    • 本公司合理怀疑涉及欺诈、洗钱、制裁规避、市场不当行为或其他违法违规活动；
    • 法律、监管机构、法院、交易所、结算机构或其他有权机构要求；
    • 本公司合理认为继续处理可能使客户、本公司或第三方承担不可接受的法律、合规或运营风险。
  5. 本公司将按适用法律及合理可行的方式通知客户处理结果，但依法不得披露原因的除外。

十一、客户陈述、保证与承诺​

客户在提交申请时并在转仓完成前持续陈述、保证并承诺：

  1. 客户具有签订及履行本协议、发出转仓指示的完全权利和授权；
  2. 所有提交资料均真实、准确、完整、有效且不存在重大遗漏；
  3. 拟转仓证券来源合法，客户享有合法权益，且除已向本公司书面披露并获接受者外，不存在留置权、押记、质押、信托、第三方权益或其他处分限制；
  4. 转仓不违反任何适用法律、法院命令、合同义务、制裁措施或第三方权利；
  5. 客户不会利用转仓服务从事洗钱、恐怖融资、欺诈、逃税、市场操纵、规避制裁或其他违法违规活动；
  6. 客户将及时更新资料、回应查询并配合本公司及第三方机构进行审核。

十二、责任与赔偿​

  1. 本公司将以合理谨慎的方式处理转仓申请，但不保证任何申请必定获批、在特定时间完成或按客户预期方式完成。
  2. 在适用法律允许的最大范围内，对于因以下事项导致的延迟、失败、差额、机会损失或其他损失，本公司不承担责任：
    • 客户提供错误、不完整、不一致或延迟提供的资料或指示；
    • 客户未向另一机构提交匹配申请或未满足其要求；
    • 第三方机构、交易所、结算机构、存管机构或通信系统的行为、不作为、延迟、拒绝或故障；
    • 市场波动、停牌、公司行动、证券限制或不可抗力事件；
    • 本公司为遵守法律、监管要求、法院命令、制裁或风险管理措施而采取的行动；
    • 客户在证券冻结或转仓期间无法交易。
  3. 本协议任何内容均不排除或限制依法不得排除或限制的责任，包括因本公司欺诈、故意不当行为、重大过失或违反不可排除的法定义务而产生的责任。
  4. 对于因客户违反本协议、提供虚假资料、无权处分证券或违法使用转仓服务而使本公司及其关联方、董事、人员或代理人遭受的合理损失、费用、索赔或责任，客户应在适用法律允许的范围内作出赔偿。

十三、资料保护与记录​

  1. 本公司将依照适用隐私法律及《隐私政策》处理客户个人资料。
  2. 客户同意本公司为提供转仓服务及履行法律、监管、审计、风险管理与争议处理义务，将资料披露给位于相关司法管辖区的第三方机构、关联公司、监管机构或专业顾问。
  3. 客户理解跨境转仓可能涉及资料跨境传输。相关接收方所在地的资料保护水平可能与客户所在地不同。
  4. 本公司可按适用法律及内部政策保存申请、签名、通讯、录音、系统日志和支持文件。
  5. 除明显错误外，本公司的电子记录、系统日志及通讯记录可作为客户指示和处理过程的证据，但不影响客户依法提出相反证据的权利。

十四、通知与通讯​

  1. 本公司可通过 APP 通知、站内信、电子邮件、短信、网站公告、电话或客户协议约定的其他方式向客户发送通知。
  2. 客户应确保联系方式持续有效并及时查看通知。APP 或站内信通知在发送至客户账户时视为送达；电子邮件或短信在发送至客户登记地址或号码且未收到无法送达提示时视为送达；网站公告在发布时视为送达，但适用法律要求其他送达方式或期限的除外。

十五、协议修改​

  1. 本公司可因法律监管变化、市场或结算规则变化、服务调整、风险管理或其他合理原因修改本协议。
  2. 本公司将通过电子邮件通知客户；法律或监管要求立即生效，或修改仅属非重大、技术性或对客户有利时，可按适用法律允许的方式处理。
  3. 修改生效后，客户继续提交或使用转仓服务，即视为接受修改后的协议；如客户不同意，应停止提交新的转仓申请，但不影响修改生效前已产生的权利和义务。

十六、适用法律与争议解决​

  1. 本协议受新西兰法律管辖并据其解释，但客户所在地适用法律中不得通过协议排除或限制的强制性规定仍然适用。
  2. 因本协议或转仓服务产生或与之相关的争议，双方应先善意协商解决。
  3. 协商不成的，双方不可撤销地同意将争议提交新西兰有管辖权的法院专属管辖；在法律允许的范围内，双方同意奥克兰为适当审理地点。
  4. 本条不限制任何一方向有管辖权的法院申请紧急、保全或禁令救济，也不影响客户依法向有权监管机构或适用的争议解决机构提出投诉的权利。

十七、其他条款​
