# 选股入门

选股不是只看短期涨跌。可以先用一份固定检查清单，确认自己理解公司、价格和可能承担的风险，再决定是否进一步研究。

## 1. 先理解公司做什么

1. 公司主要靠什么产品或服务赚钱。
2. 收入和利润是否长期依赖单一客户、地区或产品。
3. 所处行业是增长、成熟还是明显下行。
4. 自己是否能用一句话说明购买这只股票的理由。

## 2. 检查基本财务状况

- **收入与利润：**观察多年趋势，不只看单个季度。
- **现金流：**利润增长时，经营现金流是否同步改善。
- **负债：**关注偿债压力、利率变化和短期到期债务。
- **股本变化：**持续增发可能摊薄每股权益。

## 3. 看懂常用指标 {#market-indicators}

- **价格与涨跌幅：**反映市场近期交易结果，不代表公司价值已经确定。
- **成交量：**成交活跃度的参考；成交较少的股票可能更难按预期价格成交。
- **总市值：**股价乘以已发行股份数量，用于理解公司规模。
- **市盈率（PE）：**价格相对盈利的指标；亏损公司可能没有有效市盈率。
- **市净率（PB）：**价格相对账面净资产的指标，不同行业可比性不同。

## 4. 写下买入前的风险边界

1. 计划投入的金额是否影响日常生活和应急资金。
2. 哪些事实变化会推翻原来的判断。
3. 能否承受价格明显波动或长期不涨。
4. 是否过度集中在同一只股票、行业或市场。

:::warning 重要提示
本文仅用于介绍一般研究方法，不构成投资建议、收益承诺或个股推荐。证券价格可能上涨或下跌，投资前请独立判断并留意自身风险承受能力。
:::
