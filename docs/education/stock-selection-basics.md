# 选股入门

选股不是只看短期涨跌。可以先用一份固定检查清单，确认自己理解公司、价格和可能承担的风险，再决定是否进一步研究。

## 1. 先理解公司做什么

1. 公司主要靠什么产品或服务赚钱。
2. 收入和利润是否长期依赖单一客户、地区或产品。
3. 所处行业是增长、成熟还是明显下行。
4. 自己是否能用一句话说明购买这只股票的理由。

## 2. 检查基本财务状况

- **收入与利润**：观察多年趋势，不只看单个季度。
- **现金流**：利润增长时，经营现金流是否同步改善。
- **负债**：关注偿债压力、利率变化和短期到期债务。
- **股本变化**：持续增发可能摊薄每股权益。

## 3. 看懂常用指标 {#market-indicators}

价格和各项市场指标反映特定时间的交易或财务数据，不代表公司的价值或未来表现已经确定。不同市场、数据供应商和证券类型的计算口径也可能略有差异。

### 基础指标

- **最高｜最低**：当日截至当前的最高成交价和最低成交价。
- **今开｜昨收**：当日开盘价和上一个交易日的收盘价，是判断当日价格变化的常用参考。
- **成交额｜成交量**：成交额是成交金额合计；成交量是成交股数或手数合计。两者可用于观察交易活跃度和流动性。
- **总市值**：当前股价乘以总股本，用于理解公司的市场规模。
- **市盈率 TTM**：当前股价相对过去 12 个月每股盈利的倍数。公司亏损或盈利接近零时，该指标可能为空、为负或参考意义有限。
- **换手率**：一定期间内成交量相对股份数量的比例，用于观察股票交易活跃程度。分母可切换为流通股或总股本，默认使用流通股。

### 高级指标

- **总股本**：公司已经发行的股份总数，包括可流通和受限制的股份。
- **市盈率（LYR，静态）**：当前股价相对最近一个完整财年每股盈利的倍数，不反映本财年最新盈利变化。
- **流通值**：可自由交易股份按当前股价计算的市场价值；部分数据源也称流通市值。
- **市账率（PB）**：当前股价相对每股账面净资产的倍数。资产结构不同的行业不宜直接比较。
- **52 周最高｜52 周最低**：过去 52 周内的最高价和最低价，用于观察当前价格所处区间。
- **流通股**：目前可在市场自由交易的股份数量。
- **振幅**：一定期间内最高价与最低价的差额相对参考价格的比例，用于观察价格波动幅度。
- **量比**：当前平均每分钟成交量与过去若干交易日同期平均每分钟成交量的比值；大于 1 通常表示成交较平时活跃。
- **股息**：公司在指定期间内每股派发的现金股息。
- **股息率**：每股年度股息相对当前股价的比例。历史股息率不代表未来派息。
- **每手份数**：该市场每一标准交易手包含的股份数量。
- **历史最高｜历史最低**：数据记录期内出现的最高价和最低价，可能受复权方式及数据起始日期影响。
- **平均值**：指定指标在所选期间内的算术平均值；具体含义取决于当前页面展示的指标和时间范围。
- **换股比率**：一份 ADR 代表的相关普通股数量，或普通股与存托凭证之间的约定转换比例。
- **流通市值**：当前股价乘以流通股数，即 `流通市值 = 当前股价 × 流通股数`。

### 核心指标

- **ADR 换算价**：把 ADR 价格按汇率和换股比率换算为相关普通股的可比价格，即 `ADR 换算价 = ADR 现价 × 汇率 ÷ 换股比率`。实际比较还应考虑报价货币、交易时间和费用。
- **相对港股**：ADR 换算价相对对应港股现价的溢价或折价，通常以百分比显示。
- **当前查看的这只股**：标明核心指标所对应的当前证券，避免在比较 ADR、港股或其他上市类别时混淆。
- **时间戳**：标明行情或换算结果的更新时间。跨市场比较时，应留意交易时段和报价时间可能不同。

## 4. 写下买入前的风险边界

1. 计划投入的金额是否影响日常生活和应急资金。
2. 哪些事实变化会推翻原来的判断。
3. 能否承受价格明显波动或长期不涨。
4. 是否过度集中在同一只股票、行业或市场。

:::warning 重要提示
本文仅用于介绍一般研究方法，不构成投资建议、收益承诺或个股推荐。证券价格可能上涨或下跌，投资前请独立判断并留意自身风险承受能力。
:::
