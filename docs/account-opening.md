# 开户

完成 APP 账户注册后，按页面提示申请开立证券账户。注册手机号、设置邮箱和密码属于“注册”流程，不在本页重复介绍。

### 1. 选择开户类型

选择个人或企业账户。

### 2. 确认开户协议

阅读并确认开户协议。

### 3. 完成身份认证

上传身份证件，并按页面提示完成活体/身份验证。

### 4. 填写开户问卷

填写个人、职业和财务信息。

### 5. 提交审核

提交开户资料，并在页面中查看审核状态。
