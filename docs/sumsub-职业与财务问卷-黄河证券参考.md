# Sumsub 开户问卷：职业与财务信息

参考：黄河证券 App 开户流程中的「基础信息」「住址资料」「投资经验」「合规问卷」「风险披露」「申请确认」步骤。

用途：用于 Sumsub Cockpit 问卷页 `employmentAndFinanci` 录入。以下问题建议全部设为必填，除非备注中写明“条件必填”或“可选”。

## 1. 职业性质

| 字段 ID | 问题 | 类型 | 选项 / 填写要求 | 分支 |
|---|---|---|---|---|
| employment_status | 您目前的职业性质是？ | 单选 | 受雇；自雇 / 企业主；退休；学生；家庭主妇 / 主夫；待业；其他 | 根据选项显示对应分支 |

## 2. 受雇分支

显示条件：`employment_status = 受雇`

| 字段 ID | 问题 | 类型 | 选项 / 填写要求 |
|---|---|---|---|
| employer_name | 公司 / 雇主名称 | 文本 | 填写完整公司名称 |
| employer_industry | 公司所属行业 | 单选 | 金融服务；科技 / 互联网；贸易 / 零售；制造业；房地产 / 建筑；专业服务；教育；医疗；政府 / 公共机构；餐饮 / 旅游；运输 / 物流；其他 |
| job_title | 职位 / 职衔 | 文本 | 例如经理、工程师、董事、销售等 |
| employment_years | 在现公司任职年限 | 单选 | 少于 1 年；1-3 年；3-5 年；5-10 年；10 年以上 |
| employer_country_region | 公司所在国家 / 地区 | 单选或国家地区选择 | 按 Sumsub 国家地区列表配置 |
| employer_address | 公司详细地址 | 长文本 | 包含楼层 / 室号、街道、城市、省 / 州、邮编 |
| employer_phone | 公司联系电话 | 电话 | 可选，但建议收集 |

## 11. 合规声明

适用条件：所有申请人。建议放在职业与财务问卷末尾，进入风险披露前。

| 字段 ID | 问题 | 类型 | 选项 / 填写要求 | 高风险处理 |
|---|---|---|---|---|
| third_party_funds | 本账户资金是否来自第三方，或由第三方实际控制？ | 单选 | 否；是 | 选择“是”时要求说明第三方姓名、关系、资金来源 |
| beneficial_owner_self | 您是否为本账户的最终实益拥有人？ | 单选 | 是；否 | 选择“否”时要求填写实益拥有人资料 |
| pep_status | 您或您的直系亲属 / 关系密切人士是否为政治公众人物？ | 单选 | 否；是 | 选择“是”时触发强化尽调 |
| tax_residence_confirm | 您是否确认已如实申报税务居民身份？ | 单选 | 是；否 | 选择“否”时阻止提交或要求补充 |
| bankruptcy_status | 您是否正处于破产、清盘或债务重组程序？ | 单选 | 否；是 | 选择“是”时触发人工审核 |
| sanctioned_country_connection | 您是否与受制裁国家 / 地区存在居住、经营、资金来源或交易关系？ | 单选 | 否；是 | 选择“是”时触发人工审核 |

## 12. 风险确认

适用条件：所有申请人。对应黄河证券流程中的「风险披露」及「申请确认」。

| 字段 ID | 问题 | 类型 | 选项 / 填写要求 |
|---|---|---|---|
| risk_disclosure_ack | 我已阅读并理解证券、基金、债券、衍生产品、保证金交易及其他相关产品的风险披露，明白投资可能导致本金损失。 | 勾选框 | 必须勾选 |
| info_accuracy_ack | 我确认以上职业、财务、投资经验及合规声明均真实、准确、完整，并同意如资料变更会及时通知 Virtu Capital。 | 勾选框 | 必须勾选 |

## 录入建议

1. `employment_status` 放在本页第一题，并设置为主分支题。
2. 每个职业分支只显示对应问题，避免所有申请人都看到公司地址、学校名称等不相关字段。
3. 收入资产、投资经验、合规声明、风险确认对所有申请人显示。
4. 涉及“是 / 否”的合规高风险问题，建议不要自动拒绝，先进入人工审核队列。
5. 若 Sumsub 字段数量有限，优先保留：职业性质、职业分支核心信息、年收入、净资产、资金来源、投资经验、第三方资金、实益拥有人、PEP、风险确认。
