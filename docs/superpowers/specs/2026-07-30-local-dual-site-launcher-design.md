# APP 端与管理员端本地一键启动设计

## 目标

在 macOS Finder 中双击仓库根目录的 `.command` 文件，即可同时启动 APP 用户指南和管理员指南的本地开发服务。

## 启动行为

- 启动 APP 用户端：`npm run start:user`，使用 `http://localhost:3000`。
- 启动管理员端：`npm run start:admin`，使用 `http://localhost:3001`。
- 两个服务在同一个 Terminal 窗口中运行，保留各自的实时日志。
- 服务就绪后自动打开两个本地地址。

## 前置检查

脚本从自身所在目录定位仓库，避免 Finder 的工作目录差异。

启动前依次检查：

1. `node` 和 `npm` 命令是否可用。
2. 根目录依赖是否已经安装。
3. `3000` 和 `3001` 端口是否已被占用。

检查失败时，脚本显示明确的中文提示并等待用户按键关闭，不自动安装依赖，也不强制结束已有进程。

## 进程与退出处理

两个 npm 命令作为脚本的子进程启动。用户按 `Ctrl+C`、关闭 Terminal 窗口，或其中一个服务异常退出时，脚本会结束另一个服务，避免残留后台进程。

## 验证

采用 Shell 语法检查和可替换命令的行为测试，覆盖：

- 前置条件不满足时拒绝启动。
- 两个启动命令均被调用。
- 任一服务退出后会清理另一个服务。
- 脚本可由包含空格的路径启动。

最后在本机短暂启动两个真实服务，确认 `3000` 和 `3001` 均可响应，再正常停止。
