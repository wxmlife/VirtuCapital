# 账户与安全

账户资料、登录密码、交易密码与安全建议请查看本页、[设置语言与偏好](/app-guide/guides/settings) 和 [常见问题](/faq)。

![账户资料页面](./assets/11_account_info.png)

:::warning 资金安全
交易密码应与登录密码保持不同。任何出入金或转仓操作前，请再次核对收款账户、券商资料与证券数量。
:::
