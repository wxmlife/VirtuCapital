# 平台内股票转让

平台内股票转让与券商间转仓不同，是把 Virtu Capital 账户中的股票转给另一位 Virtu Capital 用户。

1. 进入“资产 → 股票转让”。
2. 在“转让给”中搜索接收方 UID、手机号或邮箱。
3. 搜索并选择股票，确认可转让数量。
4. 选择交易类型，填写数量和约定价格。
5. 阅读风险声明并勾选确认。
6. 点击“提交股票转让申请”。
7. 保存系统生成的交易码，在记录页查看审核状态。

![平台内股票转让页面](../assets/09_stock_transfer.png)

:::warning 提交前检查
请确认接收方身份、股票代码、数量和约定价格。提交后不要重复创建相同申请，以免造成重复审核。
:::
