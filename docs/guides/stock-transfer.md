# 平台内股票转让

平台内股票转让用于两位 Virtu Capital 客户之间转让股票，不是把股票转至其他券商。转让方和接收方都必须是已开户的 VC 客户。

## 先理解交易类型

| 类型 | 含义 | 页面中的对价 |
| --- | --- | --- |
| MIT | 平台内部结算。双方约定股价，由平台按“约定股价 × 数量”计算对价并完成内部股票与资金结算 | 约定股价 × 数量 |
| OTC | 场外交易。APP 内只处理股票转让，资金由双方在场外按约定结算 | 显示为 0 |

BSN 是支持本次转让的业务证明材料。请按页面要求上传真实、清晰且能对应双方、股票和交易安排的 BSN 证明。

## 操作步骤

### 1. 进入股票转让页

进入“资产 → 股票转让”。

![平台内股票转让页面](../assets/09_stock_transfer.png)

### 2. 选择接收方

使用接收方 VC UID、手机号或邮箱搜索，并与对方再次核对姓名和 UID。不要仅凭昵称判断接收方身份。

### 3. 选择股票和交易类型

选择可转让股票和数量，再选择 MIT 或 OTC：

- MIT：填写双方约定股价，核对系统计算的对价。
- OTC：页面对价为 0；双方自行完成场外资金结算，并保留相关证明。

### 4. 上传 BSN 并确认

上传 BSN 证明，检查接收方、股票代码、数量、交易类型、约定股价和对价后提交申请。

## 提交后的冻结与撤销

- MIT 申请提交后，为保证结算，转让方股票和接收方相应资金可能被冻结。
- OTC 申请提交后，转让方股票可能被冻结；APP 内不会按对价划转资金。
- 在申请尚未进入审核、匹配或结算前，如果记录页提供“撤销”，可发起撤销。
- 撤销成功后，再等待股票或资金解除冻结。已开始结算、已完成或页面无撤销入口时，不要重复提交，应联系客户支持。

:::warning 安全提示
只向已核实身份的 VC 客户转让股票。提交前确认 UID、股票、数量、MIT/OTC 类型和 BSN 文件；不要因对方催促而绕过核验，也不要向任何人提供验证码、登录密码或交易密码。OTC 的场外收付款风险由交易双方自行核实和承担。
:::
