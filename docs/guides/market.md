# 查看市场行情

市场行情属于“股票交易”模块，用于了解市场整体表现、发现标的并进入股票详情，不应只根据单一指数或榜单直接下单。

### 1. 进入市场页

进入底部“市场”。

市场页会显示市场状态和更新时间；休市时仍可查看行情和准备订单。

### 2. 选择市场

选择“港股”或“美股”，横向滑动指数卡片查看其他指数。

| 市场 | 指数示例 | 主要用途 |
| --- | --- | --- |
| 港股 | 恒生指数、恒生科技指数、国企指数 | 观察香港大盘、科技板块和主要中资企业的整体表现 |
| 美股 | 标普 500、纳斯达克综合指数、道琼斯工业平均指数 | 观察美国大盘、科技成长股和大型成熟企业的整体表现 |

### 3. 搜索或浏览股票

在搜索框查找股票或基金，也可以从“热门股票”或“涨幅领先”列表进入股票详情。

## 如何结合页面数据做初步筛选

静态指南不提供“最近适合买什么”的结论，因为指数和个股数据会持续变化。可以按 APP 当前数据使用以下方法：

1. 先看主要指数的当日涨跌和一段时间趋势，判断是多数板块同步变化，还是少数板块带动。
2. 再看热门股票、涨幅榜和成交量，区分“关注度高”与“基本面适合自己”。
3. 如果科技指数相对强，可进一步研究盈利、现金流和估值；如果防御板块相对稳定，可研究负债、现金流和分红能力。
4. 打开具体股票详情，核对价格、K 线、成交量、买卖盘和公司财务状况，再决定是否加入自选。

例如，当多个主要指数同步上涨时，可以理解为当日市场整体相对偏强；如果只有科技指数明显较强，可以继续研究盈利、现金流和估值较稳的科技企业，但不能直接把指数表现当作个股买入信号。个股位于涨幅榜前列但成交量不足时，也需要警惕价格波动和成交困难。

:::warning 行情示例不是推荐
页面截图中的指数、价格和榜单仅用于说明操作。历史涨跌、热门关注或资金流向都不能保证未来表现。
:::
