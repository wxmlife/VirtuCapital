# 查看账户资产

### 1. 进入资产页

进入底部“资产”。

![账户资产页面](../assets/03_assets.png)

### 2. 查看资产概览

查看总资产、未实现盈亏和收益率。点击眼睛图标可以隐藏或显示金额。

### 3. 查看余额和持仓

在“账户余额”查看各币种可用和冻结金额；在“持仓”查看股票数量、成本、现价、市值和盈亏。

### 4. 使用业务功能入口

从资产页的业务功能入口进入出金、订单、转仓等功能。结单入口位于“我的 → 我的结单”。
