# 查询与筛选订单

### 1. 进入订单页

进入“资产 → 订单”。

![已加载完成的订单查询页面](../assets/zh-Hans/trade/05-orders.png)

:::tip 等待订单加载
进入页面后先等待加载完成，再搜索或筛选。网络较慢时不要连续点击筛选按钮，以免误以为当前没有订单。
:::

### 2. 搜索或筛选订单

输入订单号、股票代码或股票名称搜索，也可以按状态、买卖方向和订单类型筛选。

### 3. 查看订单详情

点击订单查看订单价格、数量、金额、已成交数量和当前状态。

### 4. 撤销订单

对系统仍允许撤销的订单，在订单详情中点击撤单并确认。\
部分成交的订单只能撤销尚未成交的部分，最终状态以页面结果为准。
