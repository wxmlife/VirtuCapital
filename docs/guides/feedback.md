# 提交意见反馈

### 1. 进入意见反馈页

进入“我的 → 反馈建议”。

### 2. 选择反馈类型

选择与问题相符的类型：

- **业务反馈**：业务操作中遇到的问题，例如转入股票、转出股票、出金或业务申请进度异常。
- **产品反馈**：APP 页面或功能本身的问题与建议，例如开屏显示异常，或希望增加选股器等功能。

### 3. 填写问题说明

用一句话写清问题、发生时间和页面入口。按需上传截图，最多 9 张，总大小不超过 10 MB。

可以按以下结构填写：

```text
发生时间：
操作入口：
实际结果：
预期结果：
相关业务申请号（如有）：
```

上传前遮挡密码、验证码、完整身份证件号码和与问题无关的账户资料。

### 4. 提交反馈

点击“提交”。
