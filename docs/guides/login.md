# 登录与注册

## 登录

1. 打开 APP，点击“Get started”。

![Virtu Capital 欢迎页](../assets/login/01-welcome.png)

2. 选择国家/地区码并输入手机号。
3. 点击“Get code”，输入验证码。
4. 点击“Sign in”。

![手机号登录页面](../assets/login/02-phone-login.png)

也可以点击“其他登录方式”，使用邮箱和密码登录。

## 注册

在登录页点击“立即注册”，按页面填写手机号、验证码和账户资料。注册完成后，继续进入“开户”模块完成身份认证。

![手机号注册页面](../assets/login/03-register.png)

输入测试号码并取得验证码后，确认区号、手机号和验证码无误，再点击“下一步”。

![填写注册验证码](../assets/login/04-register-filled.png)

:::warning 验证码
验证码有时效。不要把验证码提供给任何人；多次收不到时，先确认区号和手机号，再重新发送。
:::
