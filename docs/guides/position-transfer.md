# 转入与转出股票

进入“资产 → 转仓”。转仓分为“转入股票”和“转出股票”，两者都需要准备券商资料、账户资料和持仓结单。

![股票转仓入口](../assets/10_position_transfer.png)

## 转入股票

从其他券商转入 Virtu Capital：

1. 选择“转入股票”。
2. 选择市场：港股或美股。
3. 填写转出券商名称、CCASS/DTC 编号、联系人电话和邮箱。
4. 填写转出账户类型与账户姓名。
5. 按页面继续填写股票、数量和文件资料。
6. 检查信息后提交转仓申请，并在右上角查看记录。

## 转出股票

从 Virtu Capital 转出至其他券商：

1. 选择“转出股票”。
2. 填写接收券商名称、CCASS/DTC 编号和联系人资料。
3. 填写接收方账户号码、账户类型和账户姓名。
4. 选择股票并填写数量。
5. 上传或填写所需结单与申请资料。
6. 检查后提交，并在转仓记录中跟进状态。

:::warning 同名账户
转入和转出通常要求券商账户姓名一致。提交前请核对市场、编号、账户号码和股票数量；资料错误会导致申请退回或延迟。
:::
