# 设置语言与偏好

### 1. 进入设置页

进入“我的 → 设置”。

![设置页面](../assets/13_settings.png)

### 2. 切换语言

在“语言设置”切换简体中文、繁体中文或 English，切换后立即生效。

### 3. 设置显示偏好

在“涨跌颜色”选择价格颜色偏好；也可以查看版本信息，异常时点击“清除缓存”。

### 4. 退出登录

点击“退出登录”离开当前账户。
