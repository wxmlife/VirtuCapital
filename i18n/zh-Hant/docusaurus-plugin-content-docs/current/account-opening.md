# 開戶與身份認證

註冊手機號驗證成功後，先設置暱稱、郵箱、登錄密碼和六位數字交易密碼，然後閱讀並同意用戶協議與隱私政策。

![設置賬戶資料和密碼](./assets/opening/01-after-registration.png)

賬戶註冊完成後，繼續按頁面進入開戶與身份認證流程：

### 1. 選擇開戶類型

註冊手機號並驗證驗證碼後，選擇個人或企業賬戶。

### 2. 確認開戶協議

閱讀並確認開戶協議。

### 3. 完成身份認證

上傳身份證件，並按頁面提示完成活體/身份驗證。

### 4. 填寫開戶問卷

填寫個人、職業和財務信息。

### 5. 提交審覈

提交開戶資料，並在頁面中查看審覈狀態。
