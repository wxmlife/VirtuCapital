# 選股入門

選股不是隻看短期漲跌。可以先用一份固定檢查清單，確認自己理解公司、價格和可能承擔的風險，再決定是否進一步研究。

## 1. 先理解公司做什麼

1. 公司主要靠什麼產品或服務賺錢。
2. 收入和利潤是否長期依賴單一客戶、地區或產品。
3. 所處行業是增長、成熟還是明顯下行。
4. 自己是否能用一句話說明購買這隻股票的理由。

## 2. 檢查基本財務狀況

- **收入與利潤**：觀察多年趨勢，不只看單個季度。
- **現金流**：利潤增長時，經營現金流是否同步改善。
- **負債**：關注償債壓力、利率變化和短期到期債務。
- **股本變化**：持續增發可能攤薄每股權益。

## 3. 看懂常用指標 {#market-indicators}

- **價格與漲跌幅**：反映市場近期交易結果，不代表公司價值已經確定。
- **成交量**：成交活躍度的參考；成交較少的股票可能更難按預期價格成交。
- **總市值**：股價乘以已發行股份數量，用於理解公司規模。
- **市盈率（PE）**：價格相對盈利的指標；虧損公司可能沒有有效市盈率。
- **市淨率（PB）**：價格相對賬面淨資產的指標，不同行業可比性不同。

## 4. 寫下買入前的風險邊界

1. 計劃投入的金額是否影響日常生活和應急資金。
2. 哪些事實變化會推翻原來的判斷。
3. 能否承受價格明顯波動或長期不漲。
4. 是否過度集中在同一只股票、行業或市場。

:::warning 重要提示
本文僅用於介紹一般研究方法，不構成投資建議、收益承諾或個股推薦。證券價格可能上漲或下跌，投資前請獨立判斷並留意自身風險承受能力。
:::
