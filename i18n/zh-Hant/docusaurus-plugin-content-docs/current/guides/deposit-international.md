# 如何入金

:::warning APP 暫時不支持入金
當前版本暫不開放入金功能，請不要根據舊截圖或舊流程向任何賬戶匯款。
:::

如需獲得可用證券資產，可以使用：

- [轉入股票](./position-transfer)：把本人其他券商賬戶中的股票轉入 Virtu Capital。
- [平臺內股票轉讓](./stock-transfer)：由另一位 Virtu Capital 客戶按平臺規則向您的賬戶轉讓股票。

舊版入金功能不在當前指南中展示。\
功能重新開放並完成頁面、賬戶和流程覈驗後，再恢復具體操作教程。
