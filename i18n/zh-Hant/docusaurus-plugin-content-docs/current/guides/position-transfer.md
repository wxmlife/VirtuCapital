# 轉入與轉出股票

進入“資產 → 轉倉”。轉倉分爲“轉入股票”和“轉出股票”，兩者都需要準備券商資料、賬戶資料和持倉結單。

![股票轉倉入口](../assets/10_position_transfer.png)

## 轉入股票

從其他券商轉入 Virtu Capital：

### 1. 選擇轉入股票

選擇“轉入股票”，並選擇市場：港股或美股。

### 2. 填寫轉出券商資料

填寫轉出券商名稱、CCASS/DTC 編號、聯繫人電話和郵箱。

### 3. 填寫賬戶和股票資料

填寫轉出賬戶類型與賬戶姓名，並按頁面繼續填寫股票、數量和文件資料。

### 4. 提交併跟進

檢查信息後提交轉倉申請，並在右上角查看記錄。

## 轉出股票

從 Virtu Capital 轉出至其他券商：

### 1. 選擇轉出股票

選擇“轉出股票”。

### 2. 填寫接收券商資料

填寫接收券商名稱、CCASS/DTC 編號和聯繫人資料。

### 3. 填寫賬戶和股票資料

填寫接收方賬戶號碼、賬戶類型和賬戶姓名，選擇股票並填寫數量。

### 4. 上傳資料並提交

上傳或填寫所需結單與申請資料。檢查後提交，並在轉倉記錄中跟進狀態。

:::warning 同名賬戶
轉入和轉出通常要求券商賬戶姓名一致。提交前請覈對市場、編號、賬戶號碼和股票數量；資料錯誤會導致申請退回或延遲。
:::
