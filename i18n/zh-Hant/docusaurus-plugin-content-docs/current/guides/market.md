# 查看市場行情

市場行情屬於“股票交易”模塊，用於瞭解市場整體表現、發現標的並進入股票詳情，不應只根據單一指數或榜單直接下單。

### 1. 進入市場頁

進入底部“市場”。

市場頁會顯示市場狀態和更新時間；\
休市時仍可查看行情和準備訂單。

![市場首頁顯示港股指數、市場狀態和熱門股票](../assets/zh-Hans/market/01-market-overview.jpg)

### 2. 選擇市場

選擇“港股”或“美股”，橫向滑動指數卡片查看其他指數。

| 市場 | 指數示例 | 主要用途 |
| --- | --- | --- |
| 港股 | 恒生指數、恒生科技指數、國企指數 | 觀察香港大盤、科技板塊和主要中資企業的整體表現 |
| 美股 | 標普 500、納斯達克綜合指數、道瓊斯工業平均指數 | 觀察美國大盤、科技成長股和大型成熟企業的整體表現 |

### 3. 搜索或瀏覽股票

在搜索框查找股票或基金，也可以從“熱門股票”或“漲幅領先”列表進入股票詳情。

## 如何結合頁面數據做初步篩選

靜態指南不提供“最近適合買什麼”的結論，因爲指數和個股數據會持續變化。可以按 APP 當前數據使用以下方法：

1. 先看主要指數的當日漲跌和一段時間趨勢，判斷是多數板塊同步變化，還是少數板塊帶動。
2. 再看熱門股票、漲幅榜和成交量，區分“關注度高”與“基本面適合自己”。
3. 如果科技指數相對強，可進一步研究盈利、現金流和估值；如果防禦板塊相對穩定，可研究負債、現金流和分紅能力。
4. 打開具體股票詳情，覈對價格、K 線、成交量、買賣盤和公司財務狀況，再決定是否加入自選。

例如，當多個主要指數同步上漲時，可以理解爲當日市場整體相對偏強；如果只有科技指數明顯較強，可以繼續研究盈利、現金流和估值較穩的科技企業，但不能直接把指數表現當作個股買入信號。個股位於漲幅榜前列但成交量不足時，也需要警惕價格波動和成交困難。

:::warning 行情示例不是推薦
頁面中的指數、價格和榜單僅用於說明操作。歷史漲跌、熱門關注或資金流向都不能保證未來表現。
:::
