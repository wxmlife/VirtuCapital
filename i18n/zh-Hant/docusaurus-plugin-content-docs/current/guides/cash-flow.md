# 查看資金流水

資金流水用於覈對賬戶資金因交易和業務處理產生的變化。

## 1. 進入流水頁

![資金流水頁面](../assets/zh-Hans/cash-flow/01-cash-flow.png)

## 2. 查看收入和支出

頁面頂部彙總所選計價幣種的**總收入**和**總支出**。\
列表按日期顯示業務名稱、股票名稱或代碼、發生時間、處理狀態、金額和幣種。

金額前的正負號表示資金變化方向，應同時結合業務名稱判斷：

- 買入股票、出金通常產生資金支出。
- 賣出股票通常產生資金收入。
- 股票轉讓或劃轉會按實際處理結果顯示相應變化。

## 3. 使用類型篩選

點擊“全部、入金、出金、買入、賣出、劃轉”等類型篩選記錄。\
篩選後仍要覈對日期、幣種和狀態，失敗或處理中記錄不應當作最終到賬結果。

:::warning 入金篩選不代表功能開放
流水頁保留“入金”篩選項，可用於查詢歷史記錄或兼容不同賬戶狀態。\
當前 APP 暫時不支持新建入金申請，功能狀態以資產頁實際業務入口和最新平臺通知爲準。
:::
