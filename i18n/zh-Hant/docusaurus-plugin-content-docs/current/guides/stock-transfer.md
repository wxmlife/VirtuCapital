# 平臺內股票轉讓

平臺內股票轉讓與券商間轉倉不同，是把 Virtu Capital 賬戶中的股票轉給另一位 Virtu Capital 用戶。

### 1. 進入股票轉讓頁

進入“資產 → 股票轉讓”。

![平臺內股票轉讓頁面](../assets/09_stock_transfer.png)

### 2. 選擇接收方和股票

在“轉讓給”中搜索接收方 UID、手機號或郵箱。搜索並選擇股票，確認可轉讓數量。

### 3. 填寫轉讓信息

選擇交易類型，填寫數量和約定價格。

### 4. 提交申請

閱讀風險聲明並勾選確認，點擊“提交股票轉讓申請”。提交後保存系統生成的交易碼，並在記錄頁查看審覈狀態。

:::warning 提交前檢查
請確認接收方身份、股票代碼、數量和約定價格。提交後不要重複創建相同申請，以免造成重複審覈。
:::
