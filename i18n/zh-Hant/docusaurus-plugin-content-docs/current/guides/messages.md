# 查看消息中心

消息中心用於集中查看交易、資產、安全和系統通知。

## 1. 進入消息中心

在“我的”頁面點擊右上角信封；出現紅點表示存在未讀消息。

![消息中心頁面](../assets/zh-Hans/messages/01-message-center.png)

## 2. 篩選消息

使用“全部、交易、資產、安全、系統”篩選消息。頁面上方會顯示未讀數量，也可以選擇“全部標記已讀”。

## 3. 查看業務進度

轉倉、股票轉讓等業務可能通過消息通知“已提交、通過初審、通過審覈、已完成”等狀態。點擊消息查看詳情時，應同時覈對申請編號和 APP 業務記錄，不能只憑通知標題判斷最終結果。

## 4. 處理安全通知

收到密碼變更或異常登錄等安全消息時：

1. 先確認是否爲本人操作。
2. 如果不是本人操作，立即修改登錄密碼和交易密碼。
3. 不要向任何人提供驗證碼或密碼，並儘快聯繫客戶支持。

:::info 覈對業務記錄
請以本人頁面顯示的申請編號、賬戶信息和業務記錄爲準；消息標題不能代替最終處理結果。
:::
