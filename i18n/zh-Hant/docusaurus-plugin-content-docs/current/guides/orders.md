# 查詢與篩選訂單

### 1. 進入訂單頁

進入“資產 → 訂單”。

![已加載完成的訂單查詢頁面](../assets/zh-Hans/trade/05-orders.png)

:::tip 等待訂單加載
進入頁面後先等待加載完成，再搜索或篩選。網絡較慢時不要連續點擊篩選按鈕，以免誤以爲當前沒有訂單。
:::

### 2. 搜索或篩選訂單

輸入訂單號、股票代碼或股票名稱搜索，也可以按狀態、買賣方向和訂單類型篩選。

### 3. 查看訂單詳情

點擊訂單查看訂單價格、數量、金額、已成交數量和當前狀態。

### 4. 撤銷訂單

對系統仍允許撤銷的訂單，在訂單詳情中點擊撤單並確認。\
部分成交的訂單隻能撤銷尚未成交的部分，最終狀態以頁面結果爲準。
