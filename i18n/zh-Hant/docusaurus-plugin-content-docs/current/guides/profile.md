# 進入“我的”頁面

![“我的”頁面](../assets/zh-Hans/profile/01-profile.png)

頁面可查看暱稱、VC UID 和認證狀態，並進入：

- **賬戶資料**：查看和維護個人賬戶信息。
- **我的結單**：篩選、下載或發送日結單和月結單。
- **用戶協議與隱私政策**：查看當前協議文件。
- **反饋建議**：提交業務反饋或產品反饋。
- **設置**：調整語言、行情顏色等偏好。

右上角信封是消息中心入口；出現紅點表示有未讀消息。可在消息中心查看交易、資產、安全和系統通知。複製 VC UID 或向客戶支持提供 UID 時，應覈對完整號碼。

詳見：[查看消息中心](./messages)。

:::tip 先確認認證狀態
部分資產和交易功能僅對已完成開戶及認證的賬戶開放。\
入口缺失時，先查看頁面上的認證狀態。
:::
