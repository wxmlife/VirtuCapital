# 查看股票詳情

股票詳情頁包含最新價、漲跌幅、開盤/最高/最低、成交量、成交額、估值數據、圖表、逐筆成交和買賣盤。

### 1. 打開股票詳情

從自選或市場頁點擊股票。

![股票詳情頁面](../assets/14_stock_detail.png)

### 2. 查看行情和圖表

在“行情/輪證”之間切換，並在“分時、日K、周K、月K”等週期之間切換。

### 3. 進入交易

查看買賣盤後，點擊“交易”“快買”或“快賣”。

### 4. 管理自選

點擊右上角圖標加入或移除自選。
