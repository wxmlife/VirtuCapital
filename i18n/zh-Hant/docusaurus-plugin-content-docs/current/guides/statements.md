# 查看與獲取結單

結單是賬戶業務記錄文件，可用於覈對交易、持倉和轉倉資料。

## 1. 進入結單頁

進入“我的 → 我的結單”。頁面頂部會顯示結單賬戶 UID。

![我的結單列表](../assets/zh-Hans/statements/01-statements.png)

## 2. 篩選結單

使用左側下拉框選擇全部結單、日結單或月結單；使用右側下拉框選擇月份。等待列表加載完成後再選擇文件。

- **日結單**：按交易日生成，適合覈對某一天的賬戶記錄。
- **月結單**：按月份彙總，適合查看較長週期的賬戶記錄。

沒有顯示結果時，先確認結單類型和月份是否正確，再等待列表加載，不要連續反覆切換篩選項。

## 3. 預覽並獲取

點擊一條結單，覈對結單類型、日期、UID和文件格式。PDF 可選擇：

- **保存本地**：下載到當前設備。
- **發送郵件**：發送到頁面確認的郵箱。

兩種方式只是選擇如何接收現有結單，不會重新生成一份新的結單。

![結單預覽與接收方式](../assets/zh-Hans/statements/02-statement-detail.png)

:::warning 文件安全
結單含賬戶和資產信息。下載後妥善保管，不要發送給不相關人員；用於轉倉時，只提交到確認無誤的券商或平臺頁面。
:::
