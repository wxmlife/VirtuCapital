# 查看賬戶資產

### 1. 進入資產頁
![賬戶資產頁面](../assets/zh-Hans/03_assets.png)

\
**查看資產概覽**

:::tip
頁面頂部可以切換資產計價幣種
:::


| 頁面字段 | 如何理解 |
| --- | --- |
| 總資產 | 按當前計價幣種折算的賬戶資產合計 |
| 股票總價值 | 當前持倉股票按頁面價格計算的總市值 |
| 當前可用資金 | 當前可用於交易或業務申請的資金 |
| 未實現盈虧 | 仍在持倉中的股票相對成本產生的浮動盈虧 |
| 今日盈虧 | 按頁面統計口徑計算的當日盈虧變化 |


### 2. 查看餘額和持倉

在“賬戶餘額”查看各幣種的 **可用餘額** 和 **凍結餘額**。\
凍結餘額通常與未完成訂單或正在處理的業務有關，暫時不能重複使用。\
![賬戶資產頁面](../assets/zh-Hans/asset/01.png)
\
在“持倉列表”查看當前持倉的
- **股票代碼**
- **可用股票數量**/**凍結股票數量**
- **成本價**、**現價**、**持倉市值**
- **持倉盈虧**。
\
點擊持倉的股票可以繼續查看股票詳情。


![賬戶資產頁面](../assets/zh-Hans/asset/02.png)

### 3. 使用業務功能入口

從資產頁的業務功能入口進入：

- **出金**：提交或查詢出金申請。
- **流水**：查看買入、賣出、出金、股票轉讓等資金變化。
- **訂單**：查詢股票訂單及成交狀態。
- **股票轉讓**：在符合規則的 VC 客戶之間轉讓股票。
- **轉倉**：在 Virtu Capital 與其他券商之間轉入或轉出股票。

:::tip 結單功能
結單：查看交易日或月的賬戶資產結算。
 入口位於“我的 → 我的結單”。
:::

:::warning 入金功能狀態
當前 APP 暫時不支持入金。資產頁沒有入金業務入口時，請勿根據舊截圖或舊流程匯款；可以通過轉入股票或平臺內股票轉讓獲得證券資產。
:::
