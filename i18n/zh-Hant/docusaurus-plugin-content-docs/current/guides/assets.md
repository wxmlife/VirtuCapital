# 查看賬戶資產

### 1. 進入資產頁

進入底部“資產”。

![賬戶資產頁面](../assets/03_assets.png)

### 2. 查看資產概覽

查看總資產、未實現盈虧和收益率。點擊眼睛圖標可以隱藏或顯示金額。

### 3. 查看餘額和持倉

在“賬戶餘額”查看各幣種可用和凍結金額；在“持倉”查看股票數量、成本、現價、市值和盈虧。

### 4. 使用快捷入口

從資產頁的快捷入口進入入金、出金、賬單、訂單和轉倉。
