# 管理自選股

### 1. 進入自選頁

進入底部“自選”。

![自選股頁面](../assets/zh-Hans/watchlist/01-watchlist.png)

### 2. 添加自選股

點擊“+ 添加自選”或頂部搜索框，輸入股票代碼或名稱。搜索頁的“熱門關注”可用於發現近期關注度較高的股票；它只反映頁面推薦，不代表適合所有用戶。

![搜索股票和熱門關注](../assets/zh-Hans/watchlist/02-search-popular.png)

搜索結果右側的黃色勾選表示股票已經加入自選；再次點擊可以移除。也可以進入股票詳情後點擊右上角圖標操作。

### 3. 打開行情詳情

自選列表會顯示市場標籤、股票代碼、最新價、漲跌幅、分時走勢和數據更新時間。點擊股票行可以直接打開行情詳情和交易入口；不要把右側勾選按鈕當作進入詳情的入口。

### 4. 管理自選列表

使用“港股/美股”篩選市場。點擊“設置”調整排序，或進入編輯模式刪除標的。
