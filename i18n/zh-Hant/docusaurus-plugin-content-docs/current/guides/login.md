# 登錄與註冊

## 登錄

### 1. 打開 APP

點擊“開始使用”進入登錄流程。

![Virtu Capital 歡迎頁](../assets/login/01-welcome.png)

### 2. 輸入手機號

選擇國家/地區碼，並輸入手機號。

:::warning 注意
當前僅支持香港地區手機號註冊。
:::

### 3. 獲取驗證碼

點擊“獲得驗證碼”，輸入短信驗證碼。

### 4. 登錄

點擊“登錄”。

![手機號登錄頁面](../assets/login/02-phone-login.png)

:::tip 其他登錄方式
使用手機號註冊完成後，也可以點擊“其他登錄方式”，使用郵箱和密碼登錄。
:::

## 註冊

### 1. 進入註冊頁

在登錄頁點擊“立即註冊”，按頁面填寫手機號、驗證碼和賬戶資料。

![手機號註冊頁面](../assets/login/03-register.png)

### 2. 填寫驗證碼

輸入測試號碼並取得驗證碼後，確認區號、手機號和驗證碼無誤，再點擊“下一步”。

![填寫註冊驗證碼](../assets/login/04-register-filled.png)

### 3. 繼續開戶

註冊完成後，繼續進入“開戶”模塊完成身份認證。

:::warning 驗證碼
驗證碼有時效。不要把驗證碼提供給任何人；多次收不到時，先確認區號和手機號，再重新發送。
:::
