# 註冊與登錄

沒有註冊過 Virtu Capital 的新用戶，應當先在登錄頁點擊“**立即註冊**”；\
註冊完成後，可以使用 **手機號驗證碼** 或 **郵箱密碼** 登錄。

## 註冊

### 1. 進入註冊頁

打開 APP，點擊“開始使用”後進入 **登錄界面**。

在登錄頁底部點擊 **“立即註冊”**。

![手機號登錄頁面](../assets/zh-Hans/login/02-phone-login.png)

### 2. 驗證手機號

選擇 **國家/地區碼** ，輸入**手機號**並獲取**驗證碼**。

確認區號、手機號和驗證碼無誤後，點擊“下一步”。

:::warning 注意
當前僅支持香港地區手機號註冊。
:::

![手機號註冊頁面](../assets/zh-Hans/login/03-register.png)



### 3. 設置賬戶資料

按頁面填寫**暱稱**、**郵箱**、**登錄密碼**和**六位數字交易密碼**，並**勾選閱讀同意用戶協議與隱私政策**。

:::warning 注意
這裏完成的是 APP 賬戶註冊，不等同於證券賬戶開戶。
:::

![設置賬戶資料和密碼](../assets/zh-Hans/login/05-account-details.png)

完成註冊後返回登錄頁，再使用剛纔註冊的手機號或郵箱登錄。

:::warning 驗證碼與密碼
驗證碼有時效，不要向任何人提供驗證碼或交易密碼。

多次收不到驗證碼時，先檢查區號和手機號，再重新發送。
:::

## 登錄

### 1. 打開登錄頁

點擊“開始使用”進入登錄頁。

![Virtu Capital 歡迎頁](../assets/zh-Hans/login/01-welcome.png)

### 2. 輸入手機號和驗證碼

選擇國家/地區碼，輸入已經註冊的手機號。

點擊“獲取驗證碼”並填寫短信驗證碼，然後點擊“登錄”。

:::warning 注意
當前手機號入口僅支持香港地區手機號。
:::

![手機號登錄頁面](../assets/zh-Hans/login/02-phone-login.png)

:::tip 其他登錄方式
完成註冊後，也可以點擊“**郵箱密碼登錄**”，\
使用註冊時填寫的郵箱和登錄密碼進入 APP。
:::
