# 設置語言與偏好

### 1. 進入設置頁

進入“我的 → 設置”。

![設置頁面](../assets/zh-Hans/13_settings.png)

### 2. 切換語言

在“語言設置”切換簡體中文、繁體中文或 English，切換後立即生效。

### 3. 設置顯示偏好

在“漲跌顏色”選擇價格顏色偏好；也可以查看版本信息，異常時點擊“清除緩存”。

### 4. 退出登錄

點擊“退出登錄”離開當前賬戶。
