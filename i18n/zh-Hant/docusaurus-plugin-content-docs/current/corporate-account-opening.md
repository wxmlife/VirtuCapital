# 企業開戶

企業開戶由工作人員協助完成。請直接撥打 APP 企業開戶頁面顯示的客服電話，或使用頁面顯示的客服郵箱聯繫工作人員。工作人員將在系統中幫助您完成開戶。

## 1. 進入企業開戶頁面

在“選擇開戶類型”頁面點擊“企業開戶”，進入企業開戶聯繫方式頁面。

## 2. 聯繫工作人員

在企業開戶頁面選擇客服電話或客服郵箱聯繫工作人員，並按照工作人員的指示提供對應的企業信息和開戶資料。

![在選擇開戶類型頁面選擇企業開戶](./assets/zh-Hans/corporate-account-opening/01-select-account-type.jpg)

:::info 聯繫方式以 APP 頁面爲準
企業開戶頁面顯示的客服郵箱、客服電話及服務時間可能更新。聯繫時請以 APP 當前頁面顯示的信息爲準。
:::

:::warning 按工作人員指示提交資料
不同註冊國家或地區、企業類型及賬戶需求所需的資料可能不同。請按照工作人員的具體指示準備並提交對應信息和資料，不要通過非官方聯繫方式傳送企業或個人敏感資料。
:::
